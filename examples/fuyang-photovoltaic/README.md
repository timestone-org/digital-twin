# 阜阳烟厂光伏大屏

本地项目「阜阳烟厂」中的「光伏 · 智慧运维」按旧系统 2026-11-17 的配置迁移。
画布为 1920 × 1080，包含 24 个节点；复用信息卡片、仪表卡片、趋势曲线、对比柱图、
数据表格、布局容器和信息列表，新增风向罗盘与数字时钟。

## 实际迁移

- 采集源：KEPSERVER，65 个点位；旧 OPC UA 地址映射为新点位编码，地址本身保留。
- 台账：`guangfu`，每 10 秒聚合；74 列，其中 65 列点位与 9 列公式。
- 台账：远程切换时主台账 862,539 行，测试台账 60 行；切换后继续采集。
  原始值、公式结果、人工修正、样本数、求值错误及原有录入信息分别保留。
- 素材：15 个 SVG，逐字节核对；保存旧 ID 到新 ID 的映射，大屏引用使用本地新 ID。
- 原始点位归档：已迁移旧系统 228,685,781 条（截止北京时间
  2026-11-17 11:24:43），并合并本地新版采集的 120,663 条；新采集继续写入远程新库。
- 测试大屏保留为「光伏 · 测试数据备份」，实际大屏改接 `guangfu`。

保留旧公式，包括办公楼高低位合成、累计总电量的 `+800000`、
预测今日发电量的 `+321` 和预测功率的 `×1.04`。这些是原配置口径，
不是经过校准的新预测模型。装机 1300 kWp 仍为原系统占位假设。

风向、风速按语义接到独立数据槽；光合瞬时值与日累计量分别使用自己的列，
并在趋势图采用独立单位轴。运行分析用布局容器与两个信息列表分别呈现预测值、目标和状态，
自动状态按原目标的达成率判定；原来关闭自动判断的功率行保留固定状态。

本次原始备份、压缩历史、素材、ID 映射与迁移后的 JSON 位于本机
`~/Downloads/fuyang-migration-2026-11-17/`。业务数据不放进 Git。

远程存储切换的核对记录另存于
`~/Downloads/fuyang-server-migration-2026-11-17/`；独立存储部署及连接方式见
[`docker/FUYANG_STORAGE.md`](../../docker/FUYANG_STORAGE.md)。绿色生产评价大屏也使用
同一组新存储，模板、历史报告和评价台账的迁移说明见
[`docs/MODULE_GREEN_PRODUCTION_MIGRATION.md`](../../docs/MODULE_GREEN_PRODUCTION_MIGRATION.md)。

## 测试配置

`dashboard.json` 是迁移前的测试版可导入大屏，`test-data.json` 包含
`fuyang_pv_demo_20261117` 台账定义、66 个指标和 60 行分钟数据。
二者供脱离现场时检查布局；不是实际运行大屏的数据来源。

卡片的图标素材按 `icons/` 取回，背景图片按 `images/` 取回。
两种素材共用引用格式但不共用存储前缀，由回归测试覆盖。
