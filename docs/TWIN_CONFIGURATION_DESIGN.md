# 3D 孪生配置工作面

## 单动画控制

模型加载后从同一份 GLB 读取动画名称、时长与驱动节点。空名或重名动画不可单独配置，
需要在模型中提供唯一名称。动画名称是模型内的稳定身份，显示名称可独立修改。
模型替换后缺失的控制配置保留并提示失配，不按列表位置猜测对应关系。

`model.animations.controls` 按文档序保存逐动画规则。每条规则可关闭、固定播放或按点位
条件播放，支持数值比较、循环/单次、暂停/复位、续播/重播与无有效数据策略。
点位布尔值映射为 1/0；空值、无效数值不参与比较。条件持续成立时不重复 reset；
单次播完等待条件重新触发。无数据默认暂停，不能把未知当成 0。
实时通道断开后点位不再用于动画条件计算，待恢复有效数据再继续。

旧 `enabled/clips/speed` 是未单独配置动画的缺省行为，新增 controls 默认为空；
单动画规则优先于旧缺省，因此无须打开一个隐藏的总开关才能使用点位控制。

新增绑定槽 `animationValues[i].value`，i 是 controls 的文档序。
`bindingRows` 与 `twinSceneValues` 共用该顺序，文档修改经 `remapTwinBindings` 搬迁绑定，
配置与绑定一起保存和撤销；控制方式切换不删除已有绑定。
模块清单同时导出服务端目录，保证保存时认可此槽。

## 配置预览

配置预览默认打开，部件选择自动隔离其关联节点并取景，视点选择使用对应的机位、
注视点与 FOV。模型动画选择框住动画涉及的节点；无法推导节点时保留全景。
主编辑视口维持静止，动画试播在预览工作面进行。

选择对象触发取景；部件颜色等属性变更保持当前观察角度。隔离只属于预览实例，
恢复时还原节点可见性，不修改配置。异步模型加载完成后仍应用当前选择，避免
选择早于加载导致预览退回默认视点。更换画质档位也重新加载对应模型。

单独试播、暂停和复位均为内存状态，不修改绑定、配置或设备值。切换对象后结束
试播。整屏运行预览继续走 ModuleRenderer，保持标题、控件和设计像素比例。

## 验证

真实 three 动画轨验证逐动画独立启停、重复数据不重播、暂停续播与复位；绑定重排
与 JSON 往返验证持久化契约。组件测试验证目录选择、配置和试播事件；真实页面
验证部件隔离、视点构图和动画列表。未保存的新点位绑定明确提示需保存后才推送。

## 卡片、点击与漫游验证

选中信息牌、锚点、箭头或能量流时，预览围绕该对象取景；能量流取景覆盖整条路径。
配置预览临时显示选中对象，正式显隐规则仍在整屏运行预览中验证。
信息牌同时显示平面卡片，以实际运行态 `panelCard` 生成标题、字段、单位及样式。

部件预览提供模型、详情卡片和点击验证三个工作面。进入详情或点击字段后，预览自动
切到对应工作面。详情卡片读数与模型保持当前草稿，并可打开完整运行态详情弹窗，
验证装配关系与弹窗尺寸。平面卡片本身不参与部件点击事件。

近距/远距预演直接展示所配动作；按当前视距测试则复用运行态距离门禁。
未配置远近分界时，远距预演明确提示该动作在运行时无法进入。预览中的部件事件不
转发给大屏联动规则，避免测试动作影响其他模块。

模拟值按场景值通道与实体/字段身份索引，不按显示顺序或字段标签索引。
只覆盖当前对象上已明确修改的字段，零值、布尔值、文本和无数据均保留其语义；
未修改字段继续使用实时值。切换对象清空模拟状态，切回整屏运行只读取真实绑定。
模拟值不进入文档、撤销栈或保存请求，也不写入设备。

漫游预览复用同一条时间线，可选择整条路线或单个起止段，显示当前段飞行加停留的
完成百分比。右侧预览按钮控制小窗，不移动编辑视口。退出漫游配置停止播放；
模型尚未加载时等待就绪后再执行播放请求。原配置关闭自动漫游时也可临时试播。

## 批量配置与配置效率

左侧固定显示对象类别与配置状态筛选，可单独查看部件、动画、视点、信息牌等类型。
配置问题按诊断结果筛选，未绑定按实际绑定行筛选；筛选保留文档序号，不改变绑定。
从视口或关联入口选择对象时展开对应分组；列表滚动位置在当前编辑会话内按分组记住。

右侧固定显示当前对象，关联入口只使用现有的上级/子部件、视点引用、锚点和路径引用，
动画按实际驱动节点关联，不按显示名称推测关系。视口提供聚焦、全览、上一视角与
临时隔离。隔离会隐藏未登记到部件的背景节点，退出时恢复原编辑态显隐。
专注配置隐藏当前页面的平台导航并缩小留白，不修改全局侧栏偏好。

批量复制以一个部件为来源，独立勾选常态外观、染色、详情样式、详情字段和点击距离。
目标的 id、名称、模型节点、上级关系与取景不被复制。详情样式保留目标标题与副标题。
绑定不从来源复制，同键字段保留目标绑定；移除字段或关闭染色造成的解绑数量会提前展示。
整批经 `TwinDoc.commit` 应用，一次撤销同时恢复配置与绑定。

批量点位替换支持部件、信息牌、锚点、箭头、能量流和动画，按字面量替换选中对象的
实时绑定 nodeKey，并逐条展示前后身份。目标按完整 nodeKey 在采集目录中核对，
限制四路并发；不存在、无法识别或匹配结果过多时不允许应用。更改输入、范围或关闭
弹窗会取消在途请求并作废旧校验，防止旧结果批准新计划。应用只调用 commitBindings，
保留绑定 id，一次撤销整批；保存仍使用原有版本校验，不写设备值。
