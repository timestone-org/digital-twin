# 知识库吉祥物视觉方案

以用户提供的「北京烟厂吉祥物」六张 PNG 为角色参考，保留蓝色服装、黄色鹿角、浅蓝腹部、珊瑚色脸颊和灰猫搭档，补绘适合知识服务的欢迎、查阅和阅读姿态。

## 场景与动效

| 场景 | 页面位置 | 动作与触发 |
| --- | --- | --- |
| 欢迎探索 | 知识库对话的无消息首页 | 吉祥物招呼姿态，轻摆与星光播放两轮后停止；下方四个问题入口沿用原提问事件 |
| 认真找答案 | 管理页检索试验台、对话处理中 | 放大镜与书本姿态；只有真实检索或回合处理中持续轻摆，结束或等用户回答时停止 |
| 知识陪伴 | 管理页引导横幅、未选知识库时 | 吉祥物阅读、灰猫伏在书堆；轻浮两轮后停止 |

检索初始状态提示如何提问；正在检索时先显示等待状态；完成后显示真实结果或原有未命中提示。后端降级说明继续展示，不以吉祥物替代错误信息。

## 页面设计

- 对话首页：中心吉祥物、主题标题、两列快捷提问卡片；手机宽度改为单列。对话有内容后欢迎区退出，保留原消息、引用和实时点位卡片。
- 管理页：紧凑横幅提供「选择知识库 → 上传资料 → 检索与提问」引导，窄屏收起步骤装饰，列表与操作仍沿用原组件。
- 吉祥物颜色属于品牌插画；背景、边框、文字、星光与光晕均读取现有主题 token。

## 实现与素材

透明 PNG 位于 `web/app/src/assets/knowledge/`，由 imagegen 基于原图生成，不覆盖原始素材。运行时使用 PNG + SCSS 关键帧实现三组动态插画，不依赖 GIF 播放器或新的动画库；没有逐帧角色肢体动画。

共用组件为 `KnowledgeMascot.vue`。全部动效支持 `prefers-reduced-motion: reduce`，装饰性图像对屏幕阅读器隐藏，等待状态提供文本和 `role="status"`。关键帧集中在 `_animations.scss`，没有定时器或持续的 JavaScript 动画循环。

- 知识库、知识库对话与时间线 211 条定向测试通过，另有图标契约 10 条通过。视觉组件覆盖率：行 100%、分支 85.71%、函数 100%。
- 生产构建和仓库本地快闸；预览临时文件不随产品交付。
- 浏览器检查深浅主题、390px 窄屏、透明图片加载与减少动态效果偏好。
- 本地 8080 真实管理页与对话页检查；「二月能耗」查询从等待动效切换到 8 条真实结果。390px 对话页需使用外壳已有的折叠导航，消息区内部滚动，输入区固定底部。
