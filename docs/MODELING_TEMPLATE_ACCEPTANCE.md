## 已交付行为

- 保留原有算子画布、训练执行器、模型版本、公式绑定和部署机制。
- 设计可发布为有名称和版本的不可变模板；同一模板可创建多个参数独立的模型。
- 模型页面提供逐节点表单、完整 JSON、完整 JSON Schema、训练状态、历史结果、版本发布和部署。
- 第三方只需查看、运行和按需发布权限；账号 API 密钥可完成建模管理，部署密钥用于线上调用。
- 配置全量原子保存，配置和修订号同快照读取；未知节点、无效参数、过期修订号和在途训练期间的配置变更均拒绝。
- 模板发布、实例创建、训练和部署支持幂等键；模板状态和实例配置写入同事务审计，保留来源 IP、操作者与变更前后内容。

## 真实服务 E2E

真实 NGINX、auth API、platform API、Redis、PostgreSQL 与 worker 组成验收链路。
通过 HTTP 创建合成台账和模板，签发仅有 `modeling:view/run/publish` 权限的账号 API 密钥，
确认模板发布被 403 拒绝，再完成 Schema 读取、模型创建、完整参数保存、训练幂等重放、
worker 成功运行、模型版本发布、部署、签发部署密钥和真实预测。

合成数据为 `能耗 = 2 × 温度 + 3 × 负荷 + 5`，部署后输入温度 25、负荷 430，
得到预测 1345（误差小于 0.001）。未使用假训练结果或外部生产数据。
复现脚本为 `server/services/platform-server/scripts/verify_modeling_templates.py`，
环境配置与接入顺序见 [接入指南](MODELING_TEMPLATE_GUIDE.md)。

## 页面审核

浏览器实际完成：选模板创建模型、填写名称和编码、集中配置、保存、训练、自动状态更新、
发布版本、部署及一次性密钥显示。另验证无效 JSON 不丢草稿、不允许保存或训练；
修正并保存后修订号推进，训练期间参数锁定。第三方账号页面隐藏模板设计入口。
深色与浅色主题均已查看，滚动区域、表格和卡片、弹窗及字段可读。

## Standards

工程审核发现的配置/修订读取竞态、JSON 草稿被覆盖、异步弹窗关闭、审计证据不足均已修正。
