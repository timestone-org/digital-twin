# 报告模板与自动生成

报告是数据台账的表达层：模板 + 报告期生成一份可下载的 Word 文档。
参考实现位于 DigitalTwinBK 的 `apps/report`；本项目的架构、接口和工程规范优先。

## 边界

- 业务归 `platform_server/apps/report`，数据归 `platform` schema。
- 台账取数只经 `dataset.services` 公开面，使用人工修正与计算之后的生效值。
- API 负责模板、指标、定时规则及生成请求；CPU 密集的文档导入与生成由 worker 执行。
- Word 只有服务端一种生成路径；编辑器试算展示数据，下载交付真实生成产物。
- 对象存储复用 `lib.objectstore`，不复制旧项目的存储、认证或后台任务基础设施。

## 功能契约

模板保留 ProseMirror 文档结构、指标表与页面设置。业务节点包括行内数字
`metricRef`、条件文本 `condText`、块级图表 `dsChart` 与台账表格 `dsTable`。
支持 Word 导入、纯文本与表格版式、折线和柱状图、页面尺寸、页边距、页眉页脚、
分页、水印及目录。导入或渲染无法保留的内容必须列出警告，不允许静默丢弃。

报告期支持日、月、季、年，按显式业务时区切半开区间 `[start, end)`。
指标支持期内聚合、最新值、指定期偏移和指标表达式；表达式复用台账公式引擎。
取数必须有行数上限，触顶在试算与产物生成记录中明确标识。
精确数值以字符串传输，时刻以 UTC RFC3339 传输，响应回显业务时区。

## 持久化与执行

模板、定时规则、生成记录和审计分别持久化。模板修改必须携带预期版本，
冲突返回 409；生成记录保存模板快照，后续编辑不能改变已经提交的任务。
定时规则同一报告期依赖数据库唯一约束去重。创建与生成接口支持调用者范围的
`Idempotency-Key`；数据库提交成功后才能投递带 `traceparent` 的队列消息。
worker 对重复消息幂等，超时与进程中断必须收敛为可见失败，不能永久停在生成中。
定时总开关默认关闭，手动生成不依赖该开关；页面显示真实有效配置。

## 接口与权限

资源前缀为 `/api/v1/platform/report-templates`、`report-renders`、
`report-schedules`。校验、试算、生成和导入采用 `POST …:verb`。
生成提交返回 202，模板创建返回 201 + Location，删除返回无正文 204。
模板与规则列表使用页码分页，生成记录使用游标分页。

读面 `report:view`；模板和试算 `report:manage`；生成及下载 `report:render`；
定时规则 `report:schedule`。下载不能被 GET 读权限兜底放行。
后端鉴权规则、服务端权限判断和前端门禁必须逐字对齐。

## 验收

1. 创建模板、插入本期与上期指标、条件文本、图表及表格，试算可核对。
2. 保存后重新打开，正文、数据引用和页面设置保持一致。
3. 生成并下载 Word；中文、数字、表格、图表与报告期正确。
4. 导入 Word 能继续编辑，不支持的内容有明确清单。
5. 定时到期生成，同期重复触发不重复出稿；开关关闭不触发。
6. 权限不足、空数据、截断、并发编辑、重复提交、存储失败和 worker 中断有测试。
7. 本地静态闸、契约、真实数据库集成、前端交互与构建通过，并检查实际 Word 产物。

## 当前实现与启用

页面入口为 `/reports`，包含模板列表、结构化正文编辑、生成记录及定时规则。
正文编辑使用与参考实现一致的 Umo Editor，并通过其 Tiptap 扩展面保留四类业务节点；
编辑器的导出入口关闭，手动和定时生成共用 worker 的同一条生成管线。Umo 的公式、
图表等外部资源随前端构建并走同源路径，不依赖公网 CDN。新建模板之后，添加指标、
插入指标数字或条件文本、图表和表格，
保存后选择报告期即可生成。页面设置支持纸张、方向、厘米边距、字号、页眉页脚、水印和目录。

模板编辑器登记为 AI 助手的 `report-editor` 工作面。助手可读取当前未保存草稿，
辅助增改指标、插入文本与四类业务节点、调整页面设置，并调用同一套模板校验和
试算接口核对结果。助手的写操作只修改浏览器里的草稿，不调用保存或生成端点；
用户审阅后仍需手动保存，避免模型把未确认内容直接持久化。

部署沿用 `docker/README.md` 的流程：

1. 安装更新后的锁文件依赖，重建 platform、auth 与前端镜像。
2. 先执行 platform 的 `alembic upgrade head`，新增四张 `report_*` 表。
3. 执行 auth 的 `python -m scripts.seed`，登记四个报告权限码与对应路由规则。
4. 更新 platform 的 API 与 worker、auth 和边缘前端进程。
5. 需要周期自动生成时，设置根环境变量 `PLATFORM_REPORT_SCHEDULE_ENABLED=true`，
   再更新 API 与 worker；界面会显示真实开关。关闭开关不影响手动生成。

不能只更新 API：Word 的生成与导入实际运行于 worker。位图后备路径依赖
`fonts-noto-cjk`，它已纳入 platform 镜像，修改后必须重建镜像。
新增迁移是纯扩展；代码回滚时保留这些表，不在部署回滚中删除报告数据。

## 数据口径与边界

- 一次试算总共读取最多 50,000 行，单窗口最多 20,000 行；展示值也有整体预算。
  截断和预算耗尽会显式显示。HTTP 试算限制 20 秒，worker 任务限制 300 秒。
- 生成队列以 100 个在途任务为背压水位；定时规则暂缓，手动提交收到 429。
- 数字保留 `value_kind`，避免小数字符串在条件表达式里变成文本排序。
  聚合使用 Decimal；派生表达式继承当前台账公式引擎的数值语义。
- `anchor=latest` 如使用早于报告期的数据，会返回 `is_stale` 与明显提示。
- 定时规则从最近完整一期开始；中断之后每拍补一期，水位只向前推进。
- 模板已有生成历史或规则时不能删除，应停用以保留历史；规则同理。
- 只读权限只能看生成状态，完整试算快照要求生成或管理权限；未保存的 Word
  导入内容仅上传者在具有管理权限时可读。
- Word 导入保留段落、基础文本标记、表格顺序及第一节页面设置；图片和图表、
  批注脚注、多节及合并单元格等存在转换损失，导入界面展示丢失清单。
  原生 Word 图表与浏览器 ECharts 的外观并非逐像素相同。

## 模板配置工作台与第三方 API

编辑页保留 Umo 正文与页面设置，配置侧栏分为「报告数据」「模板设置」「数据核对」。
业务用户先添加指标并插入正文，选择报告期后试算；数据来源、草稿或报告期变化会
使旧核对结果失效。指标支持编辑、来源说明、单位、常用报告期选择和完整聚合方式；
表格与图表可以选择多列或多个序列，展示行数统一为 1～1000。
有未保存修改且具备管理权限时，生成入口为「保存并生成」；保存冲突或保存失败时
不继续提交。API 来源及指标随模板版本一起保存，旧模板缺少 API 配置时按空目录读取。

### 通用接口配置

第三方业务查询遵循平台 ADR-0006。管理员在 API 与 worker 共用的环境中设置
`PLATFORM_REPORT_API_CONNECTIONS` JSON 数组，例如：

```json
[
  {
    "code": "ems",
    "name": "能源管理系统",
    "base_url": "https://ems.example.test/reporting",
    "headers": {"Authorization": "Bearer REPLACE_AT_DEPLOYMENT"}
  }
]
```

以上为占位示例。真实认证值仅部署时注入，不提交 `.env`、不填入模板参数。目录为空
时现有台账报告正常使用；界面提示管理员登记连接。更改目录后同步更新 API 与 worker
进程。固定连接也可指向明确授权的内网业务系统，浏览器不接触地址、认证头或原始响应。
第一版支持服务端固定认证头（例如 Bearer、Header API Key、预先编码的 Basic）及匿名
查询；交互式登录、OAuth 动态续期、厂商签名及自动分页需各自提供适配，界面不假称支持。

在「报告数据 → 添加 API 数据源」中配置：

| 配置 | 示例与语义 |
|---|---|
| 来源名称、编码 | 月度能耗、`energy`；编码被正文或指标引用后保持稳定 |
| 已授权连接、相对路径 | 选择「能源管理系统」，路径 `/energy`；不能填完整网址、跳转路径或凭据 |
| 请求方式 | GET 或只读查询 POST；不配置外部写操作 |
| 查询参数 / JSON 请求体 | `{"start":"{{start}}","end":"{{end}}"}` |
| 报告期变量 | `{{period}}`、`{{start}}`、`{{end}}`、`{{timezone}}`；开始和结束传 UTC RFC3339，边界为 `[start,end)` |
| 报告期偏移 | 0 本期、-1 上期；偏移属于来源，消费字段不再重复偏移 |
| 数据位置 | `/data/items`；空字符串表示根，对象按一行、数组按多行 |
| 时间字段 | `/time`，相对每行，必须带时区并处于该来源报告期；留空使用报告期起点 |
| 映射列 | 如编码 `energy`、名称「用电量」、位置 `/value`、类型「数值」 |

记录及字段位置使用 [RFC 6901 JSON Pointer](https://www.rfc-editor.org/rfc/rfc6901)，
不使用点号路径或执行用户脚本。数值保留精确小数，文本、布尔和空值保留各自语义。
配置完成后从指标的数据来源选择「API · 月度能耗」和映射列，即可插入数字或文本；
同一来源的多个指标可以组成表格与图表。复制来源并设置上期偏移，可与本期指标计算环比。
被引用的来源不能直接删除，避免正文悬空引用。

### 核对、生成与故障

试算会真实调用所有已配置来源，即使尚未插入正文，也会显示各源映射行数和前五行
样例；仅展示配置中选择的列。核对结果显示时间、报告期、指标错误、陈旧与截断状态。
正式生成由 worker 重新请求，各来源只调用一次，正文、表格、图表和计算字段共享结果。
历史生成记录保存经映射的纯数据和报告快照；下载历史产物不会再次查询第三方。

单次最多 10 个来源、每源 50 列、1000 行、2 MB，单源请求预算 5 秒，整组取数 15 秒，
并受现有试算 20 秒 / worker 300 秒总预算约束。不自动分页，不自动重试；超限明确失败。
无数据不补零，类型不符、缺少字段、超窗时刻和依赖指标失败会阻止正式生成；现有陈旧、
展示截断等警告保留在试算和文档提示中。上游故障与错误可定位到对应来源，不回传 URL、
凭据或响应全文。出站目标固定、DNS 后校验和禁重定向的取舍同时参考
[OWASP SSRF 指南](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html)。

来源编码最多 60 字符，为内部 `api:` 前缀预留空间。数值字符串最多 128 字符，
有效位最多 100 位、十进制数量级绝对值最多 100；单个文本字段最多 10000 字符。
每源映射后的 JSON 累计体积仍限制为 2 MB，重复映射同一大字段不会绕过容量预算。

## 持久投递补偿与发布顺序

数据库中的 pending 生成记录作为持久待执行来源。提交后的即时 Redis 通知有硬超时，
失败不会丢掉已提交任务；报告 worker 内的补偿器不依赖定时生成总开关。补偿以数据库
时钟认领单条记录，短事务使用 SKIP LOCKED，发布在事务外执行，令牌与租约保护写回。
同一任务的重复消息只允许一次 pending → running，因而不会重复调用数据 API 或出稿。
一批硬预算 20 秒、最多 20 条，单次发布预算 5 秒、单条投递预算小于 30 秒租约；失败冷却
60 秒，成功通知后对尚未认领记录逐级退避，避免灌入重复消息。容量检查在同一短事务
串行化，手动、导入和定时并发不会越过既有在途水位。

积压 pending 不因年龄误判失败；运行中断按 started_at 收敛为可见失败，不自动重新
执行外部取数。生成详情不公开内部投递状态，失败与成功终态清除或替换这部分元数据。
Redis 暂不可用以及 Stream 消失后，worker 可以在依赖恢复后重建消费组并继续处理。

既有环境升级遵循平台 ADR-0007：先暂停报告提交/导入入口并停止、drain 全部旧 worker
和调度器，再升级全部 API，随后启动新版 worker，最后恢复入口和前端。旧 API 不理解
内部结果字段，旧 worker 不认识新 API 快照，不能长期混部。回滚保留兼容版本或先暂停
报告功能再整体处理；不能直接换回旧 worker 消费新快照。没有数据库迁移，不删除报告
数据。独立报告验收环境使用独立数据库、Redis 和存储，保留原有 8080 环境。

## Word 导入的格式保留与边界

导入保留直接格式、字符/段落样式和文档默认格式中的字体、字号、基础文字标记、颜色，
以及编辑器实际支持的对齐、左右缩进、精确首行/悬挂缩进、段前段后和行距。单位在 Word
磅值与编辑器 CSS 值之间显式换算。普通横向/纵向合并单元格保留结构，静态表格只在
明确存在表头节点时重复表头；展开网格有容量上限，并拒绝冲突跨度。

主题字体会转为固定字体并提示核对中西文字形。不支持的段落边框/底纹、页眉页脚样式/动态域、图片/图表/复杂图形、脚注批注、自动编号、多节设置以及
表格列宽/边框/底纹/留白/行高等转换损失会列入清单；显式关闭继承格式不能表达时也会
明确提示。超链接保留可见文字，转换为普通文本；不访问或复制外部关系，宏和主动内容
被拒绝。导入不是无损复制 Word 版式，正式使用前可通过预览和下载核对。

导入任务区分排队、转换、失败与完成；关闭弹窗不会取消后台处理。在同一浏览器标签页
按当前账号保存非秘密任务标识及名称/编码，刷新或重开后可继续查询，不保存 Word 正文
或凭据。切换账号会作废旧查询，创建模板或明确放弃后清除本人的恢复记录；存储不可用
仍可完成本次导入，并提示保持页面。无法转换的文件提供安全、可操作的错误原因。

## 数值边界

直接引用数值保持 Decimal 精度，复合表达式仍继承台账公式引擎的数值语义；需要全部
运算都使用任意精度时，应先统一公式引擎口径，避免报告另造一套计算规则。
