| 问题 | 实现结果 | 主要验证 |

| 同回合计划陈旧 | `plan.write` 返回完整规范化计划，下一次模型调用刷新状态块 | HTTP 流事件、持久化与模型输入三侧核对 |
| 点位详情把第一页遗漏当不存在 | 精确匹配遍历有界分页，超时或结果不完整明确失败 | 精确目标在第二页的回归 |
| 知识检索正文静默截断 | 保留完整性信息，片段明确标记截断，新增授权的 `knowledge.read_chunk`；正文窗口按预算收紧且不二次截断 | 跨库/无权限/窗口限制/完整续读；对象不存在要求重新检索 |
| 记忆错误声称可检索、混用向量 | 保存结果返回实际可检索状态；向量与请求时的模型身份原子绑定；换模型惰性补算，补算失败明确报错 | 真库测试覆盖请求期间换模型、不同维数与补算失败 |
| 报告只能读取截断提纲 | 提纲分页、正文按窗口续读；普通段落/标题按原文前置条件替换 | 长正文、后续提纲、旧原文拒绝与复杂格式保护 |
| 采集页有映射但无入口 | 新增只读助手与 `collect-inspect`；快照只包含白名单字段 | 页面挂载、权限与敏感字段排除 |
| 提示词与实际能力矛盾 | 对齐预览联动、草稿显隐、配置拒绝、保存授权、无技能读取、视觉能力和未验证措辞 | 提示词、技能、说明与前端契约回归 |
| 严格调用把未指定节点填为空字符串 | 只读节点范围统一接受省略、null 与空白；有具体身份时仍校验所属工作面 | 三个工作面回归及真实模型分页验证 |
| 相同失败参数反复执行 | 普通浏览器工具保留未执行回执后停止重复调用，参数修正和成功复读仍可继续；MCP 与旧知识库回填协议不变 | 同参数换 ID、键顺序变化、修参继续、MCP/旧协议及真库回执 |
| 旧前端误获新客户端能力 | 新增客户端工具必须由页面显式上报才下发 | 不上报/显式上报的对照回归 |

## 使用边界

- 上下文窗口由 `ASSISTANT_MODEL_CONTEXT_TOKENS` 显式配置，视觉窗口可由 `ASSISTANT_VISION_CONTEXT_TOKENS` 覆盖；字符/token 和图片预算为保守估算，不宣称精确分词。
- 报告替换只支持文本格式一致的段落/标题，复杂表格、图片及混合文本格式由正文编辑器处理。
- 记忆检索最多扫描本人最近 2,000 条，单次惰性补算最多 20 条，工具明确说明范围。
- 未将 68 个工具逐一对现场执行写操作；写操作契约与恢复路径由隔离测试覆盖，页面抽测使用只读或可撤销草稿。
