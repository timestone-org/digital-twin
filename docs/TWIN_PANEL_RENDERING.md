# 三维信息牌：原生样式与深度合成

卡片继续由 `buildPanelCard` 和原始 `styles/panel.scss` 渲染。字体、变体、布局、
图表、背景和 CSS 动画不改写为 Canvas 绘图命令；配置预览也使用同一份原生卡片。

## 层次与遮挡

从底到顶依次是场景底层缓冲、CSS3D 原生卡片、WebGL 场景前景、CSS2D 标签。
主场景每帧只渲染一次。合成器直接复制这一帧的场景缓冲，并用卡片投影范围裁剪底层；
随后透明代理面依据模型深度在前景留出卡片可见部分。卡片透明区域因此仍能看到其后的场景，
模型挡住的部分继续由前景覆盖。

代理只表示卡片、引线和阴影的覆盖范围，不承载文字或卡片样式。
布局尺寸通过 ResizeObserver 标记失效，固定尺寸不会每帧重读。
屏幕范围在齐次坐标中裁剪，跨过近裁剪面时保留仍可见的部分。

遮挡依据模型已有的深度写入设置。`depthWrite: false` 的透明模型或特效不充当深度遮挡物。
编辑手柄等 `depthTest: false` 的前景对象单独绘制，避免卡片合成盖住操作控件。

## 性能与资源

固定朝向的信息牌按相机所在侧切换卡片的水平镜像补偿，正反面文字均可正常阅读。
补偿围绕卡片自身中心执行，不改变配置旋转、挂点、引线或卡片占用位置；正交相机
按平行视线判断观看侧。两侧复用同一份 DOM 与实时字段，切面时重新计算深度覆盖范围。

- 不生成卡片图片，不编码 SVG/data URL，不创建 Image，不通过 fetch 获取牌面图片。
- 仅复用一份场景底层 Canvas 缓冲；卡片数量不会增加模型渲染次数或卡片纹理上传。
- 原有实时字段更新与 CSS 动画直接由浏览器执行。
- 卸载时释放代理几何、材质、ResizeObserver、裁剪节点与场景缓冲。
- DOM 截图通过 prepareSnapshot 保持同一合成状态，截图替身与原生卡片保持层次一致。

## 设备开关状态

字段画法 `status` 以圆灯和文案徽标显示状态，`switch` 以滑轨位置和文案显示状态。
两者均为只读显示，不触发设备写值。字段的 `state` 保存开启／关闭编码、两态文案与
颜色，以及未知状态文案。默认匹配 1／0；布尔值和文本 true／false 同样匹配，支持
现场自定义编码与反向编码。仅命中明确配置的编码才显示对应状态，其他值、无数据或
冲突编码均显示中性未知状态；收到无数据时清除上一次的激活显示。

状态配置随字段保存，换画法不改变字段顺序或绑定行。存量字段没有 `state` 时保留
原有画法。常用测点提供运行／停止、开启／关闭和故障／正常预设。

新建信息牌默认单列、宽高自适应；外观预设仅改变外观，保留当前宽高和列数。
已保存的固定尺寸和多列布局继续有效。

## 验证

`panelStyle.contract.spec.ts` 检查八种卡片与原始 HTML/SCSS 的结构、变量和动画标记一致。
合成测试检查模型渲染次数、零图片编码／请求、编辑手柄、渲染器状态恢复和资源释放。
浏览器验收必须同时检查原生样式、局部遮挡、透明背景及持续变化数据的帧耗时。
