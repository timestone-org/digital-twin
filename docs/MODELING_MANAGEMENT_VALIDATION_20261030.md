4. 检查并发索引、可空扩展字段和引用守卫；迁移无存量数据回填。

迁移恢复修复将待发布链拆为四阶段：`modeling_management_20261030` → `modeling_management_idx_20261030` → `modeling_commands_20261030` → `modeling_commands_idx_20261030`。结构阶段与并发索引阶段分别记录 revision，避免索引失败后表列已存在却无法续跑。新增 7 项阶段边界、链头和索引故障续跑契约用例先红后绿；适配器用例另模拟残留无效索引，确认再次执行先删除残留再完整建索引。

四阶段实现已在重建的隔离 PostgreSQL 完成真实故障注入：在管理索引阶段第四个索引、命令索引阶段分别将一次建索引语句替换为不存在的列，使 PostgreSQL 实际返回错误。两次失败后的数据库 revision 分别保持 `modeling_management_20261030`、`modeling_commands_20261030`；解除注入后显式执行 `upgrade head` 均成功到达 `modeling_commands_idx_20261030`，未重复创建表列。另完成 head → `f02b841ac356` → head 及 head → base → head，11 个并发索引全部存在且 `indisvalid=true`。本地日志为 `/tmp/dt-modeling-mgmt-results/migration-recovery.log`；该证据不代表客户数据库已执行迁移。

## 已验证的关键行为

- 保留旧页码和部署数组形状；精确编码核查、筛选、微秒游标、插入/删除竞态及关系查询无 N+1。
- 实例列表、详情、配置快照的嵌套 latest_run 返回真实实例与发布版本关系。
- 归档保持身份和历史，所有训练/发布/绑定/部署替代入口执行同一守卫。
- 同一部署修订并发换版只有一个成功；输入输出或规则配置改变需确认；回滚固定历史来源版本。
- 公式、部署和切换历史引用阻止物理退役，保持旧 409/41413 错误契约。
- 命令参数变化拒绝、跨账号不可读、权限不足拒绝、24 小时后仍可恢复；未知结果不自动接管。
- 删除同键重放仍为无体 204；取消已受理的命令可恢复原回执，仍须查询运行终态。
- 可信网关操作人和平台账号分别审计；未授权声明拒绝；推理日志保留账号与 trace，配额 429 返回等待头。
- 新回归/分类版本执行冻结默认值，显式 0 保留，历史格式计算行为不变；异常不发布宽松填值承诺。
- 修复共用 worker 吞掉不可重试启动异常的问题，保留显式瞬时故障的既有恢复行为。
