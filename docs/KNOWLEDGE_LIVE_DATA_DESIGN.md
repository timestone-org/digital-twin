# 知识库对话中的实时点位

用户说“查看一号机出口温度的实时数据”，助手调用 `collect.search_points`，通过
名称、描述和编码寻找点位。查询通常只含2–6个关键词，保留设备名、编号和测量量，
最多80字；索引可包含完整描述，但模型不能为查询扩写背景、权限或用途。
例如「动力换热 2#阀门 开度」。超长查询回明确错误要求重新提炼，不截断后执行，
防止截掉关键编号。编码精确匹配排在最前；自然语言用关键词与向量混合
召回。多个可能点位必须用 `user.ask` 让用户选，取消时不猜测设备。
确定后调用 `collect.watch_point`，时间线上出现实时卡片，显示名称、所属数据源、
单位、质量、采样时间。持续更新与模型答复独立，用户可以继续聊天或暂停卡片。

## 元数据与索引

- 点位描述可空，最多 1000 字；添加、编辑和批量建点均支持。
- 平台 worker 分批比较当前点位/数据源元数据与索引文本、模型签名；已有点位也
  自动补建。每5秒处理最多32条；失败条目至少60秒后才参与下一次对账，防止饿死后续点位。
  多副本重复计算可幂等写入，失败不能覆盖同版本的成功结果。保存配置不调用模型。
  每批模型调用有超时，不持数据库事务。
- 使用系统模型目录的“知识库嵌入”分配；不复制知识库服务的环境变量配置。
  未分配时仍可保存、采集和按关键词检索，响应明确提示语义检索未启用。
- 向量保存在 platform schema。只用与当前文本及模型签名完全一致的向量；
  修改期间、模型更换期间以索引未就绪表示，不把旧向量作为当前配置。
- 删除点位通过同 schema 外键级联清理索引；查询再次关联当前配置。
- 首版在 PostgreSQL 内执行向量距离查询；不把全量向量拉进 API 进程。
  归一化向量保存在 double precision 数组中，通过点积计算余弦相似度。
  不依赖安装在 knowledge schema 的库级扩展，不搬迁已有扩展。首版为精确扫描，
  适用于有限点位目录；大规模部署需要单独评估 ANN 索引与延迟预算。

## 工具与实时生命周期

工具返回有界候选与检索模式，不能返回端点地址、账号、密钥或完整供应商配置。
搜索回填给模型时，一批搜索共用700字符预算：保留完整 `node_key` 与名称，数据源
去重，省略的候选明确标注数量并提示缩小查询；不截断身份。API完整响应不变。
续推按实际工具声明、当前回执和固定提示词重新分配历史预算，必要时省略早前摘要，
避免6656 token小窗口在搜索之后撤掉 `user.ask` / `collect.watch_point`。
`collect.watch_point` 只接受平台返回的点位身份，打开前重新解析身份、名称和单位。
HTTP 与主题订阅均要求现有 `collect:view`；知识库权限不授予采集权限。
搜索未指定数据源时省略 `source_id` 或传 `null`；旧调用的空字符串同样按未指定处理。
全零UUID被拒绝，非空过滤先验证数据源存在，不能把错误范围伪装成“没有匹配点位”。

实时卡片复用 `collect:{source_id}`。发布器每15秒补全量心跳，卡片超过45秒
没收到目标点位的帧就标旧；按接收时刻判断，不能把长期稳定的采样值误判为掉线。
首值来自 WS；断线保留最后值但标为陈旧，
重连后收到新帧才恢复。暂停、清屏、切会话、卸载释放订阅和定时器。
没有首帧须提示检查数据源启用、采集运行态、发布器与实时点位上限，不能无限转圈。
卡片只展示被配置的点位；不自动添加点位、修改采集计划或下发写值。

## 验收

验证自然语言召回、编码优先、未索引及模型故障的明确降级、元数据修改作废、删除
不可命中、模型切换隔离，以及卡片首帧/增量、质量异常、断线重连、暂停恢复、
同源多卡片、历史恢复和会话切换。现场验收需要已配置的数据源、嵌入模型与对话模型。

## 部署与使用

1. 先升级平台迁移到 `e71c6a28b409`；新增可空描述和独立派生表，无回填，旧代码可运行。
2. 发布 platform API / worker / publisher、knowledge API 和前端。无需修改 collector
   或 realtime-hub；publisher 的15秒全量心跳负责读数健康确认。
3. 在系统模型供应商目录为“知识库嵌入”分配 embedding 模型，并确保已配置知识库
   对话模型。点位索引不读取 knowledge 进程的环境变量；仅环境变量配置的部署需在
   目录中补分配。模型缺席只影响语义召回，不影响点位保存或采集。
4. 给使用者已有的 `knowledge:use` 和 `collect:view` 权限，启用 OPC UA 数据源、
   添加点位并填写名称及描述。worker 自动为存量和新增点位建索引。
5. 在知识库对话输入“查看一号机送风温度的实时数据”。同义词可命中，歧义则选点位；
   卡片显示当前接收状态和采样时间，可暂停/恢复。最近6张卡片自动订阅，更早卡片停止。

长描述按256字分段嵌入并池化，不把尾部静默截断。点位实时发布仍受现有数据源的
`live_point_limit` 限制；超出覆盖范围会提示未收到数据，不自动改采集参数。
回滚时恢复旧代码，保留新结构；新历史中的卡片在旧前端只表现为普通工具记录。
