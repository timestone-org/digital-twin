# 绿色生产大屏的地图与报告展示

`geo-map` 使用旧系统随包的中国省级边界，转换为离线 GeoJSON，由 SVG 投影显示。
源为旧部署 `http://172.31.31.234:8081/dp/static/china-BLdObNQb.js`，包含 35 个要素。
数据只迁移边界与属性，未执行旧应用逻辑，不依赖公网地图 API。
支持区域高亮、中心与缩放、区域位置标签、经纬度站点及点击联动。

`report-view` 为报告展示节点。配置 `templateCode` 选择报告模板，留空时显示全部
模板中按创建顺序找到的最新成功生成记录；失败、排队、运行和 Word 导入任务不参与。
历史按服务端游标有界续读，达到上限会明确报错，不悄悄选错记录。

模块包只持有宿主注入口。应用壳通过异步组件安装认证报告宿主，负责读取、权限、
每隔 30 秒刷新、手动刷新与原件下载。新报告到达时替换展示，同一记录不重复下载；
模板快速切换与卸载使用现有 `useRacedFetch` 取消旧请求，轮询在卸载时清理。

正文按生成的 Word 原件预览；原生 Word 图表使用原文件的 DrawingML 缓存呈现，
根据包内关系在预览副本中设置定位标记，再在对应段落或表格单元格内显示图表，
保留左右布局与原尺寸。下载仍返回原件。无法恢复位置时明确报错，不将图表追加到
文末，不使用今天重新试算的值冒充旧报告。
Word 预览禁用 `altChunk` HTML，并在离屏容器渲染后提交，防止旧渲染覆盖新报告。

公开大屏无论浏览器是否同时登录，都不请求私有报告；报告展示与下载继续遵循原有
报告权限。没有报告、权限不足、刷新失败、原件渲染失败分别给出明确状态。

迁移调研与字段转换依据见 [报告迁移调研](research/GREEN_PRODUCTION_REPORT_MIGRATION.md)。
