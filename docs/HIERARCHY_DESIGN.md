# 层级图工具

功能基准为用户提供的“测试绘制层级图 / 层绘 Layerflow”案例。案例源码作为功能
参考，不把其中的开发命令或桌面部署要求当作本仓规范。边界决策见 ADR-0059。

| 案例能力 | 系统对应行为 |
|---|---|
| 项目新建、示例、复制、重命名、删除 | 工具中的层级图工作面，项目按账号隔离 |
| 节点与汇流点、拖入、端口连线、多上级 | 自绘编辑画布，保留稳定元素 ID |
| 属性、搜索、删除连线与节点 | 属性面板、搜索定位，删除节点同时断开关联连接 |
| 自动保存、手动保存、撤销重做 | 串行保存与版本冲突提示，未保存离开保护 |
| 版本恢复 | 最近 50 个保存版本，恢复创建新版本 |
| 整理、对齐、等距、网格、辅助线、微调 | 编辑工具栏及键盘操作 |
| 标准预览 | 直径 90、字号 14、两栏圆与名称框、正交走线和向下箭头 |
| 纸宽与续行 | 360～12000 px，默认 1516；高度自动延伸 |
| SVG / PNG / PDF | 整图矢量 SVG、高清 PNG、浏览器矢量打印保存 PDF |
| JSON / Excel | `layerflow.project` / `layerflow.xlsx` v1 兼容，导入为新项目 |

图文档最多 300 个元素、2000 条连接。保存前服务端独立校验身份、编号唯一、引用、
自连接、重复连接、汇流点相连及成环；空图和未完成汇流关系可以保存，出图时给出
定位诊断。长名称不得被静默截断，复杂关系无法放入图纸时提示增加宽度。

标准图排版以案例的 33 个计量节点、4 个逻辑层级、5 个展示行及末层 11 + 8 为
固定验收基准。修改编辑坐标与视口不得改变标准图；同层名称框统一大小；跨层
连线使用独立侧通道，不相关相交线留断口。

新增服务使用系统的 `lib` 配置、数据库、签名身份头、信封与生命周期机制。
创建支持 `Idempotency-Key`；更新与恢复携带当前 revision，并在同一事务内保存
文档与版本。数据库结构为独立迁移链，接入现有部署迁移作业。前端使用 `@dt/ui`、
主题 token、统一请求封装和 `useRacedFetch`。

## 配置工作面

桌面工作面分为项目导航、画布与配置面板，保留面板宽度拖动及尺寸记忆。
可用宽度不足 760 px 时通过“我的项目 / 编辑画布 / 配置”切换单个面板；
切换仅改变显示区域，节点草稿和编辑选择仍由页面持有。

工具栏区分项目概览、节点添加、编辑历史和排列操作。对齐需要至少两个节点，
等距分布需要至少三个。SVG、PNG、PDF、JSON 与 Excel 集中在导出菜单；
历史版本、复制与删除集中在项目操作菜单。

配置面板分为“节点属性 / 上下游 / 图纸设置”，统一通过编号或名称搜索定位。
节点草稿切换后保留，底部显示待应用节点数，允许统一应用或放弃未应用内容；
多选时不展示首个节点的单项编辑表单。上下游支持搜索添加、定位和移除连接，
沿用文档校验与撤销栈，移除连接不删除两端节点。

生成标准图时保留配置面板并进入图纸设置。幅宽变化后明确标记预览过期，
重新生成才更新预览；导出依然使用当前配置。只读账号可浏览关系与生成导出，
管理入口按权限隐藏，属性输入禁用。
