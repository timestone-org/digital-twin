# PLC 只读采集

首版支持 Modbus TCP。它与 OPC UA 共用一条后续数据流：驱动输出标准化读数，采集器
写 Redis 实时快照并按准入规则进入归档 Stream，writer 落 TimescaleDB，平台发布器
再把相同快照经 realtime-hub 推给采集页面和大屏。

## 配置

- 协议：`modbus_tcp`
- Endpoint：`modbus.tcp://192.0.2.10:502`
- 读取方式：轮询，数据源周期不小于 1000ms；点位采样周期可更长。实际周期取
  两者较大值，慢点位不会被快数据源拉着重复读取。
- 新建 Modbus 数据源默认不启用，完成地址与负载复核后再启用
- 采集进程还需设置 `COLLECT_PLC_READ_ENABLED=true`，并在
  `COLLECT_PLC_ALLOWED_ENDPOINTS` 中用逗号列出批准的 `IP:端口`。两者默认
  关闭或为空；未同时满足时驱动在建连前报配置错误。Endpoint 必须直接填写 IP，
  不能用可能重新解析到别处的域名。
- 可选参数：`device_id`（默认 1）、`byte_order` / `word_order`（`big` 或
  `little`）、`max_registers_per_request`（默认 120，最大 125）、
  `max_bits_per_request`（默认 512，最大 2000）、`max_requests_per_cycle`
  （默认 2，最大 8）

点位地址是零基偏移，不是设备手册里的 4xxxx 引用号：

```text
holding:0:uint16
holding:10:float32
input:20:int32
coil:0:bool
discrete:7:bool
```

支持 `uint16`、`int16`、`uint32`、`int32`、`float32`、`float64` 与位区
`bool`。寻址串的解码类型必须与点位的协议无关数据类型一致，否则该点返回 bad
质量，不会错配到相邻点位。

## 安全与负载

驱动能力明确为不支持订阅、浏览和写入；platform 和 collector 两层都会拒绝
Modbus 写值。客户端内部重试为 0，同一连接只有一个在途请求。连续地址会合成一
次读，未配置的地址空洞不会被顺带读取；不同数据源由独立异步会话并发运行，一台
PLC 卡住不会串行阻塞其它 PLC。

轮询以单调时钟上的固定时隙调度。一次读超时后跳过错过的时隙，不做“追赶式”
突发读取；失败点位写入空值与 `bad` 质量，下一次成功读取可恢复为 `good`。
每台 PLC 按点位配置的区域和地址构造批次，寄存器最多 125 个、位最多 2000 个，
再叠加数据源设置的更小上限。全部 PLC 数据源共享
`COLLECT_PLC_MAX_CONCURRENT_REQUESTS`（默认 8）的在途请求预算；连接建立也占用
该预算。被拒点位不会阻断同一 PLC 上其它有效点位，全部点位无效时不会建连。
地址分散造成的批次超过单轮预算时，驱动轮换本轮读取的批次，未读点位本轮标为
`bad`，并记录超载日志。应延长周期、收紧点位范围，或由设备负责人批准后调整
单轮请求上限。

采集器丢主后先同步撤销全部会话继续发请求的权利，再逐台拆连接；归档仍走原有
Stream 幂等落库。页面上的“已启用”“已连接”和“读数质量”是不同状态；某点
读数变为 `bad` 时不能继续把上一条正常值当新读数展示。

上线前由设备负责人确认目标 IP、站号、批准的地址清单、允许的最短轮询周期与单次
读取上限。先以禁用状态保存，从较长周期、小点数开始，在 PLC 诊断页观察通信负载
后逐步放量。出现扫描周期、通信错误或 CPU 异常时先停用数据源；无需删除点位，
历史与大屏绑定身份会保留。

## 发布与验收

先运行 platform 的纯扩展迁移，再发布兼容新协议字面量的 collector 与 platform
代码，最后开放 UI 创建新协议数据源。旧 platform 对新字面量没有兼容保证，因此
不应在旧副本仍服务时创建新协议行。回滚时先停用 PLC 数据源、关闭采集器的
`COLLECT_PLC_READ_ENABLED`，保留能识别 `modbus_tcp` 行的平台版本；数据库
约束不回滚。若必须回滚到旧平台，需要独立审查已有数据源的处置。

本地已用真实 Modbus TCP 回环服务读取 16/32 位数值，并在隔离的 Redis 与
TimescaleDB 中验证快照、归档写入及质量；16 个模拟数据源通过共享上限 8 的
并发测试。大屏的协议无关发布与 WebSocket 测试沿用原链路。真实 PLC 的容量、
厂商兼容性与大屏现场显示仍需在授权的现场验收中确认。
