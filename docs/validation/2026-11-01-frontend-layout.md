## 真实性边界

本轮证明前端实际渲染与布局，不等于真实后端联调或全功能验收。模拟数据保留 OpenAPI
响应形状，但不覆盖所有业务组合、真实素材、训练产物与模型提供方行为。

未改变数据库或凭据配置。后续使用独立验收栈的只读浏览见补验记录。

在原 640 个布局 case 之外，新增 **48 个 case**：真实 `useAiPanel`、模型选择逻辑、
`AiDock`、`AiAssistantPanel` 与 `AiComposer`，按普通 / 放大两档与四分辨率覆盖：

1. 正常就绪、已有 25% 用量与两次压缩记录。
2. 约 85%、压缩中，停止按钮保持可见。
3. 模型 PATCH 在途，禁止发送与再次选择模型。
4. PATCH 回执丢失、随后 GET 核验也失败，显示未确认状态与“重新核验模型”。
5. 手动重新核验在途，发送继续禁用。
6. GET 成功确认备用模型，清除旧模型用量，恢复发送。

PATCH，失败后一次 GET，手动核验再 GET，没有写重试。48 个 case 均无脚本异常、

## 补验：真实 UI 合成写入与布局不变量

继续在独立本地验收栈，通过当前 5174 前端 UI 创建本次专用项目和大屏，操作范围
由本轮合成名称及创建返回的 UUID 限定。实际 UI 完成以下链路：

1. Home 新建项目，HTTP 201；新建大屏，HTTP 201。
2. 打开大屏编辑器，点击添加并选中纯静态 `text-block`，在专属配置里填写验收文字。
3. 点击保存，`:replace-layout` 返回 200、`row_version=2`、一个模块；自动缩略图
   PUT 返回 200。随后真实 API 读回确认模块类型、文字和空绑定与 UI 输入一致。
4. 键盘调整左右分隔条，从 220px 到 284px。模块设计几何保持
   `x=80 / y=80 / w=320 / h=72`，保存按钮仍禁用，API 的节点与配置逐字段未变。
5. 重新打开编辑器，实际画布与配置面板均保留已保存文字；补拍 720p、1080p、2K、4K。
6. 回 Home 在项目设置中改名并点击保存，PATCH 返回 200，响应名称一致。

最终专用项目为 `01a194d5-ea37-7691-9fad-e315b92dd993`，大屏为
`01a194d5-ec57-7ad1-97e5-7065dc5cd092`。结束时先核对归属及合成名称，再逐个按
精确 UUID 删除；大屏与项目均返回 DELETE 204，随后各自 GET 返回 404。
没有按前缀批量删除、没有修改或删除既有资源，没有未知写结果或业务写重试。
该组明确包含合成业务写入，和前文 53 个只读 case 的空写请求清单相互独立。
