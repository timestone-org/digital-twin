# ADR-0065 认证审计采用可信边缘来源地址

Docker 边缘为认证管理请求写入它观察到的连接地址与服务证明，分别使用
`X-Edge-Source-IP` 和 `X-Edge-Audit-Key`。两个头由网关重新设置，使用部署已有的
边缘服务密钥校验证明。IP 经过校验后规范化并记录在认证审计事务内。

直连、旧网关与无有效来源证明的请求使用服务所观察到的连接地址。管理端点继续用
账号令牌识别操作者，并在同一业务事务写入来源。部署顺序为认证服务先上线，
Docker 网关再转发生效，旧记录按原样保留。
