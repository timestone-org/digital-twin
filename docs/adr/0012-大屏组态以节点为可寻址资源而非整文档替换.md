# ADR-0012：大屏节点稳定可寻址，并保留带版本的批量替换

画布节点与绑定拥有稳定 id、确定顺序和独立 CRUD；编辑器仍可用 `:replace-layout` 原子保存整份草稿，但必须携带期望版本，并按 id 做新增、更新、删除而不是删光重建。两条写路径共用服务端校验，未知模块、悬空引用和成环必须响亮失败。

复杂配置由模块 manifest 的 `subEditor` 声明整页编辑器，前端不按模块类型分支；该声明也导出到服务端模块目录，供 Agent 识别不可猜写的配置段。接口和字段细节见 [大屏设计](../DASHBOARD_DESIGN.md)。本条合并原 ADR-0016。
