# ADR-0019：手写前端线形是迁移期例外

目标状态仍是由提交进仓的 OpenAPI 生成后端线形类型；当前遗留的 `@dt/contracts` 仍有手写部分，本轮不做风险较高的全量改名迁移。作为临时补偿，所有前端实际读取的响应形状必须由 `check_wire_shapes.py` 覆盖，并用 TypeScript 键集与对应 `openapi.json` 逐字段比对。

这个例外只说明当前事实，不把手写类型变成长期目标。生成物与手写类型不得并行成为两个真源；完成生成迁移后应废止本 ADR 和补偿闸。
