# ADR-0019：前端线形先补一道覆盖闸，暂不改成由 openapi 生成

- 状态：已采纳
- 日期：2026-08-17
- 影响范围：`scripts/gates/check_wire_shapes.py`、`web/app/tests/contract/`、`web/packages/contracts/`
- 相关：[`agents/api-contract.md`](../agents/api-contract.md)、[`agents/code-style-typescript.md`](../agents/code-style-typescript.md)

## 背景

仓规写着「`openapi.json` 提交进仓、CI 校验一致，**前端类型由它生成**」。
实际上 `@dt/contracts` 的 23 个文件与 `app/src/api/*Wire.ts` 的 8 个文件全是**手写**的，
`web/` 下没有任何生成器依赖，也没有生成脚本。规范说的那一步从来没落地。

它的位置被一批比对用例顶上了。这批用例本身就是证据——两条都是**事后补**的：

| 事故 | 现象 | 当时的绿灯 |
|---|---|---|
| `UserListItem` 被写成 `AuthUser` | 页面读 `direct_permissions.length` 取到 undefined，**整页崩在渲染里** | typecheck / lint / 单测全绿 |
| `default` / `overridden` 实为 `default_value` / `is_overridden` | 弹窗里默认值恒空、「已覆盖」徽标永远不亮 | 同上 |

**手写的类型比真接口宽松时，编译器无从发现**——它不知道后端叫什么。

## 决策

**这一轮补一道覆盖闸，把「有没有人想到写比对用例」变成红灯；不做生成迁移。**

`scripts/gates/check_wire_shapes.py`：`openapi.json` 里能从任一 2xx 响应走到的
每一个叶子出参形状，都必须在 `web/app/tests/contract/` 的某条用例里被点名，
或者在闸门的豁免表里写明**前端不按类型读它**的理由。

⚠ 它只管「有没有人钉」，不管「钉得对不对」：键集比对必须留在 TS 那侧，
因为只有类型系统数得清 `keyof T`。两者缺一不可。

⚠ 归属按服务分：`NodeOut` 在 `opcua-server` 是地址空间节点、在 `platform-server`
是画布节点，两个完全不同的形状同名。不按服务分，钉住一个就等于把另一个也算过了。

### 不做生成迁移的理由

不是"不值得"，是**这一轮做不安全**：

1. `platform-server` 的 `openapi.json` 有 448 KB、数百个 schema。生成物的名字是
   `components['schemas']['SourceOut']` 这种形状，与 `@dt/contracts` 现在这套
   有语义的名字对不上，全量改名要动几百个 import 点。
2. `@dt/contracts` 里**不只有线形**：权限码、控件轴、前端自有的联合类型与判定
   函数都在里面。生成只能替掉其中一部分，剩下的仍要手写。
3. 半途而废最糟：生成物与手写类型并存，两套名字都活着，比现在更难判断该信哪个。

生成迁移是一件多轮的事，正确的推进顺序是**先有覆盖闸**——闸门先把缺口量出来
（本次量到 33 个出参形状没人钉），迁移才有可验证的完成判据。

## 落地时找到的东西

补齐 20 个形状的比对用例时，typecheck 当场逮到一处真缺陷：

`DashboardPublicationWire` 声明了 `id: string`，而后端 `DashboardShareOut`
的主键叫 `dashboard_id`，**根本没有 `id`**。于是 `toPublication` 每次都把
`undefined` 装进 `DashboardPublication.id`。今天无害——发布对话框把这个字段
一路 emit 出去之后没人读它；但类型说它是 `string`，谁信了谁崩。

这正是这条闸要拦的那一类，也是它值得存在的证明。

## 代价

- **豁免表要有人管**：闸门带一条自检，豁免表里出现已经不存在的形状名就红灯，
  免得它变成许愿池。⚠ 唯一合法的豁免理由是「前端不按类型读它」——
  "还没来得及写"不算，那正是这条闸要拦的东西。
- **比对用例仍是手写的**：本次那 20 个键集是从 `openapi.json` 机器生成后提交的，
  但之后加字段仍要人跟。这笔账要等生成迁移才真正清掉。
- **形状名撞车靠服务归属挡**：闸门从用例文件里读它打的是哪个服务的
  `openapi.json`。用例换写法（比如把路径拼进常量）会让归属识别失效，
  那时闸门会**误报**而不是漏报——方向是安全的。
