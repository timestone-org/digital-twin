# ADR-0041：模型目录、接入形态与订阅凭据统一归平台

`platform-server` 持有供应商、模型、用途分配和需要登录的供应商凭据；供应商的接入形态是不可原地修改的闭合集合。助手与知识库按 TTL 拉取全量目录，用显式“形态 → 适配器”注册表装配；刷新失败保留并标记旧快照，只有声明 `has_env_default` 的用途才能回退环境变量。

订阅账号使用上游私有 Codex 接入面与设备码登录。登录态由 platform 加密保存并独占刷新，消费方在每次需要时通过内部面领取短期令牌，只领不刷，避免多个服务用同一 refresh token 互相作废。目录之外不提供订阅账号环境变量档。

模型种类包括 `chat`、`embedding` 和 `rerank`。重排方言描述端点线形，配置在供应商而非模型上；重排没有环境变量回退，调用失败时检索退回融合排序并明确标注。跨服务字面量必须由契约测试锁定。

本条合并原 ADR-0026、ADR-0039 与 ADR-0040，并承接 ADR-0042 的模型目录部分；
ADR-0042 的检索策略部分由 ADR-0035 承接。
