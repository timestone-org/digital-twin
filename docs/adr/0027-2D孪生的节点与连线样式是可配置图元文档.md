# ADR-0027：2D 孪生样式是可配置图元文档

节点和连线的外观以文档中的尺寸、端口、槽位、图元和变体表达，而不是渲染层枚举分支。内置样式只是同一模型的预置数据，可被文档同 id 覆盖或恢复；运行时不得按 `styleId` 写特例。

样式随大屏配置保存，不另建后端表，保证编辑态、运行态和公开页拿到同一份定义；跨大屏复用先走导入导出。代价是预置变更会影响未覆盖的存量页面、文档更大，且图元闭合集与引用完整性必须由契约测试守住。细节见 [2D 孪生设计](../MODULE_TWIN_2D_DESIGN.md)。
