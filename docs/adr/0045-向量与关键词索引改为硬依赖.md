# ADR-0045：知识库硬依赖 pgvector 与 pg_trgm

知识库以 PostgreSQL `vector(N)` 作为唯一向量存储，并以 pgvector HNSW 与 pg_trgm GIN 提供向量和关键词检索。扩展、表与索引都由迁移建立；没有 bytea 副本、启动探测或应用层扫描回退，目标数据库不能满足前置条件时迁移应响亮失败。

嵌入是摄取必经步骤：模型不可用或维数不匹配时文档进入 failed，不能以无向量的 ready 状态蒙混过关。`KNOWLEDGE_EMBEDDING_DIMENSIONS` 同时约束列维数与环境变量模型，换维数需要迁移并重嵌存量文档。

本条完全取代 ADR-0034；索引 Protocol 只保留单一装配边界。
