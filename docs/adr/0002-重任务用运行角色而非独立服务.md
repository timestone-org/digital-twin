# ADR-0002：同一数据属主的重任务用运行角色承载

报告渲染、台账重算、训练等任务与 HTTP API 使用同一领域模型并写同一属主的表，因此由同一代码单元的 `api` / `worker` / `publisher` 角色分进程运行，而不拆成共享写路径的新服务。部署角色负责资源隔离和独立扩缩；只有出现新的领域边界或数据属主时才新增代码单元。

代价是代码单元较大，必须用 `apps/<feature>/` 边界、无 import 副作用的组合根和角色级资源限制维持内聚。部署拓扑见 [微服务架构](../ARCHITECTURE_MICROSERVICES.md)。
