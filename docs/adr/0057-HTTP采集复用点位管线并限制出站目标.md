# ADR-0057：HTTP 采集复用点位管线，并限制出站目标

`http` 是 collector 的只读驱动，一个数据源配置一个 GET 或用于查询的 POST
端点。一轮请求共享一份 JSON 响应，以 RFC 6901 JSON Pointer 解析多个点位；
`$` 表示根值。点位仍使用既有身份、类型、采样与归档参数，解析失败逐点上报
`bad`，请求失败整轮上报 `bad`。实时值、归档、大屏、台账、报告与分析继续消费
现有 Redis、TimescaleDB 与 publisher 管线，不增设 HTTP 专属历史表和推送通道。

认证支持匿名、Basic、Digest、Bearer、请求头 API Key 和 OAuth2
client_credentials。秘密仅使用既有加密 credential 字段；OAuth 令牌仅驻留
会话内存并按有效期更新。请求 options 只保存非秘密配置，拒绝 URL 凭据和常见
秘密字段；不支持 query API Key、Cookie 会话和交互式 OAuth 登录。

工业接口经常位于内网，因此通用 SSRF 的“拒绝所有内网”不适用于已经授权的
采集端点。HTTP 网络开关默认关闭，采集进程必须以精确 HTTP(S) origin 允许清单
授权数据端点及 OAuth 端点；未授权目标、云元数据与链路本地地址被拒绝。
不跟随重定向、不使用环境代理，TLS 保持证书校验。响应流有大小上限、请求有总
超时、每源单飞且全进程限制并发；客户端不重试，重连仍归 SourceSession。

云元数据地址校验由共享静态配置包统一提供，保存配置与 DNS 解析后均使用它，
包括阿里云 `100.100.100.200` 和 AWS IPv6 `fd00:ec2::254`，IPv4-mapped IPv6
先收敛为 IPv4 再校验。IPv6 scope 不参与元数据地址比对，精确 origin 授权仍保留
scope。固定 IP 后的 HTTP 连接池以 IP origin 作为键，不能区分
令牌与数据接口的原域名，因此禁用持久连接复用，逐请求以原域名握手并校验证书；
其代价是每次采集重新建立 TCP/TLS 连接。

样例 JSON 的叶子字段批量建点在前端完成，不把任意响应展示和解析放进平台
服务的现场连接边界。适配参数与启用步骤见 `docs/HTTP_COLLECT_GUIDE.md`。
