# ADR-0051：受支持业务页用账号 API 密钥换短期嵌入会话

可信宿主可用原业务路由的 `?token=<APIKey>&theme=<id>` 启动嵌入。前端立即以账号 API 密钥换取无 refresh 的 300 秒 access token，随后从 URL 清除密钥；根密钥、短票和用户信息只存在当前文档内存，续期仍重走交换端点。业务 HTTP 和 WebSocket 复用现有账号权限及 `dt.auth`，realtime-hub 不认识 API 密钥。

嵌入会话不能进入登录、个人资料、系统与 auth 管理面；其它受支持页面仍由原闸门判权。边缘对交换端点继续执行账号鉴权并额外限流，不新增匿名业务 API；静态入口使用 `no-store`、`no-referrer`、脱敏访问日志和允许嵌入的 CSP，普通页面继续禁止被 frame。

有限期和永久 API 密钥都可交换；HTTP/WS 与 HTTPS/WSS 都允许。把长期密钥放进浏览器 URL、尤其经 HTTP 传输，是明确接受的高风险例外而非安全推荐：应使用每个嵌入方独立的最小权限账号并保留人工吊销路径，已签发短票最多继续有效 300 秒。更安全的一次性嵌入票据因需要宿主后端配合而未采用。

本条吸收 ADR-0052 的最终口径；具体前端状态机见 [web 上下文](../../web/CONTEXT.md)，边缘约束见 [docker README](../../docker/README.md)。
