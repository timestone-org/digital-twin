# ADR-0059：层级图作为可选独立数据属主

层级图由 `hierarchy-server` 独占 `hierarchy` schema，提供项目、版本和校验接口，
部署通过 `hierarchy` profile 选择。它有独立安装与发布需求，不依赖采集、大屏或
台账的领域模型；服务缺席或故障不阻断其余功能。这是按产品可选安装边界新增代码
单元，对架构文档中 CRUD 默认归平台的规则作显式扩展，仍遵守 ADR-0002 的数据
属主判据、ADR-0003 的写独占以及 ADR-0004 的依赖方向。

项目归创建账号所有，节点与连接是同一份有界图文档的内部元素，不作为跨项目
数据库关系。完整保存采用期望版本条件更新，并保留最近 50 个不可变版本；恢复
产生新版本。导入总是创建新项目。API 由边缘与端点两次鉴权，前端类型由提交的
OpenAPI 生成，服务缺席时隐藏工具入口，直达页面明确报告不可用。

遵循 ADR-0028，编辑画布自绘。标准排版、Excel 编解码与导出在浏览器按需加载，
不使 API 承担渲染重任务，也不引入服务间文件调用。标准图不消费编辑坐标；SVG
与 PNG 导出整张图，PDF 使用浏览器矢量打印的保存对话框。JSON 与 XLSX 保留
案例 `layerflow` v1 格式，供桌面案例与系统之间往返。代价是导出依赖当前浏览器，
批量无人值守出图若成为需求，应在本代码单元内增加 worker 角色。
