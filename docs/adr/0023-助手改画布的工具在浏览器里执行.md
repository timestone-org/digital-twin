# ADR-0023：交互式助手由服务端模型循环与浏览器工具共同推进

状态由谁持有，工具就在哪里执行：模型循环与服务端数据工具在 `ai-assistant`，画布草稿工具在浏览器。服务端遇到客户端工具时结束 SSE 流并把待续步骤落库，浏览器执行后再次 POST 继续；因此 API 可无状态扩缩，草稿修改仍可见、可撤销。即时落库页面上的写入仍先由用户确认。

助手使用单模型加 `plan.write`，不建 planner/executor 双模型；计划落库并由前端有界续推。模型上下文只遵守“稳定内容在前、追加历史居中、易变状态在末”的排序原则，以容纳权限过滤和动态 MCP 工具，不再把实现冻结成固定四层。

画布修改默认仍是草稿。唯一主动保存例外是实时绑定：publisher 只认识已落库绑定，助手可调用浏览器侧 `dashboard.save`，但第一次保存前必须明确告知会把用户尚未保存的整份草稿一并落库；其它画布改动仍由用户保存。本条合并原 ADR-0024 与 ADR-0025。
