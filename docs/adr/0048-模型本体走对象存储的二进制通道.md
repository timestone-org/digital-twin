# ADR-0048：无法表示为 JSON 的模型本体走对象存储

可服务模型分为 JSON 参数和二进制产物两条通道。二进制只允许由本服务训练并由服务端生成对象键，存入对象存储；发布时复制到不可变模型版本自己的键，避免运行记录清理时带走线上产物，数据库只保存引用、摘要、格式和训练运行时版本。

加载前必须先校验来源与摘要，再使用受限反序列化白名单，并拒绝不兼容的运行时版本；发布时要真实取回并试算。外部二进制上传始终禁止。反序列化和推理属于阻塞计算，必须遵守 [Python 代码规范](../agents/code-style-python.md) 的事件循环隔离要求，本 ADR 不建立例外。
