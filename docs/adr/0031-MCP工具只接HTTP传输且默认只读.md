# ADR-0031：MCP 只接无状态 HTTP 子集，并默认只读

助手只支持通过 HTTP POST 调用 `tools/list` 与 `tools/call` 的无状态 JSON-RPC 子集，不启动 stdio 子进程，也不承诺 MCP 会话或 SSE 传输。这样生命周期、超时和链路传播仍沿用现有出站 HTTP 模型。

外部工具描述视为不可信数据；工具规范名为 `mcp.<server>.<tool>`，含点号或双下划线的段拒收。只有明确带只读标记的工具默认下发；写工具必须进入本地白名单，并在执行前获得用户明确确认。每个 server 独立断路，连不上时仅该路工具缺席，密钥只走请求头且无默认值。
