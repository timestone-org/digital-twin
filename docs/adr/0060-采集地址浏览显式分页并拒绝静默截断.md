# ADR-0060：采集地址浏览显式分页，并拒绝静默截断

OPC UA 大目录由 collector 持有现场会话及浏览游标，platform 转发协议无关的页大小与
续读令牌，前端显式声明分页并按需继续。整层加载、逐点读取类型与一次挂载全部行会
同时放大设备 IO、总线响应和浏览器渲染成本，因此选择有界分页及虚拟列表，子树遍历
达到节点或时间预算时明确标注未完成。

旧请求没有声明分页能力，不能把首个有界页当成完整目录返回。小目录继续完整返回，
大目录明确提示升级浏览客户端，并释放未消费的续读点；新平台收到旧 collector 的
超预算结果也明确拒绝。这是大目录旧调用的显式降级：为限制资源使用接受暂时不可用，
不接受看似成功却漏掉节点，也不通过自动无限续读恢复无界响应。

升级按 collector、platform、前端的依赖顺序完成，旧浏览器刷新后使用显式分页。
现场会话变更后游标失效，不持久化游标或跨源复用。具体预算、错误与释放规则见
[采集设计](../COLLECT_DESIGN.md#52-接口)，已有采集与配置面的职责仍遵循 ADR-0001。
