# 模型调用统一使用账号 API 密钥

第三方建模管理与已部署模型调用统一使用账号 API 密钥，经边缘与 auth-server 验证，
platform 再验证签名身份与 `modeling:view` 权限。部署只保存稳定地址、固定版本和配额，
不再签发或接受独立部署密钥，避免接入方维护两套凭据与吊销流程。本条取代 ADR-0047。

同一账号的多把密钥共享该账号在一个部署上的配额，不同部署与不同账号分别计数；
边缘按 IP 限流与单次行数上限继续保留。资源使用既有共享权限域，允许查看模型的账号
可调用任意启用部署，不增加部署所有权或第二套授权。需要隔离调用方时使用独立账号。

按本次产品要求直接切换鉴权，旧 `X-Api-Key` 部署凭据停止生效；调用方须切换为
`Authorization: Bearer <用户 APIKey>`。旧签发端点保留地址但返回 410 和迁移说明，
历史密钥列表、撤销接口与记录保留供清理；旧表和外键不删除，新的调用记录不填旧密钥 ID。
发布须同步更新 auth 路由种子、platform 与边缘配置；回滚须整组恢复，不能只退一个组件。
