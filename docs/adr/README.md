# 架构决策索引

ADR 只记录仍需长期记住的“决定与理由”。领域词、边界与不变量归 `CONTEXT.md`；
行为和接口细节归设计文档；运维与工程流程归对应规范；可从目录、配置或测试直接查到
的库存不复制进文档。后续决策取代旧决定时保留原文件号作为短墓碑，避免断链和伪造历史。

状态使用 `accepted`、`superseded by ADR-NNNN` 或 `deprecated`。同一主题的当前口径只在一份 accepted ADR 中维护。
文件名作为稳定链接可能保留历史措辞；判断当前口径时以 frontmatter 状态、文内标题和本索引为准。
