# ADR-0028：2D 孪生与建模流水线画布自绘

2D 孪生和建模 DAG 都不引入 vue-flow 一类图编辑框架。两者都必须自定义节点、端口、连线或选中语义，框架能提供的主要只剩通用视口手势，却会引入第二套坐标、选中和 store 生命周期，并迫使适配其类型边界或违反本仓禁止的双重断言。

团队接受自行维护手势、清理监听器并放弃小地图等附赠能力；两种画布只共享判据，不强行共享不同的领域模型。若出现第四块图编辑器，再依据真实公共部分评估下沉。各自细节见 [2D 孪生设计](../MODULE_TWIN_2D_DESIGN.md) 与 [建模设计](../MODELING_DESIGN.md)；本条合并原 ADR-0036。
