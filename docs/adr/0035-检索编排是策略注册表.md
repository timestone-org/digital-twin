# ADR-0035：知识检索使用策略注册表，并在会话层限定范围

检索通过 `RetrievalStrategy` 注册表提供可并存的 `naive` 基线、默认 `hybrid` 和有界 `agentic`。需要 LLM 的策略在模型缺席时明确不可用，不静默退化；重排只增强 `hybrid` 与 `agentic`，`naive` 保持无重排的纯基线。对话助手使用 `knowledge.list_bases` 与 `knowledge.search` 原语自行编排，非对话 `:ask` 只有在所选策略具备回答能力时才产出答案。

知识库对话的检索范围钉在会话上：`NULL` 表示全部，空列表非法；列库、搜索和读取原文都必须在工具层硬过滤。被删库保留为缺失项而不悄悄扩大范围，因此范围不设级联外键；变更使用行版本避免多标签静默覆盖。

本条合并原 ADR-0044。具体策略、引用和范围出参见 [知识库设计](../KNOWLEDGE_BASE_DESIGN.md) 与 [知识库对话设计](../KNOWLEDGE_CHAT_DESIGN.md)。
