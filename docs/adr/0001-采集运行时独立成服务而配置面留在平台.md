# ADR-0001：采集运行时与配置面分离，跨进程口径保持协议无关

点位与数据源的配置面留在 `platform-server`，现场连接、采样、快照和归档由 `collector-server` 独占。两者的扩缩方式、故障风险和数据所有权不同；配置面留在平台还能在进程内完成大屏绑定守卫，避免 platform 与 collector 形成双向同步 RPC。

协议知识止于 collector 的 driver。稳定点位身份、全量采集计划、命令信封、快照和运行态均与协议无关；两侧共享 `domain/collectwire` 的形状与常量，但各自持有传输、ORM 和事务。拿不到计划时 collector 空转并告警，不用旧计划猜测。

实现细节见 [采集设计](../COLLECT_DESIGN.md)、[platform 上下文](../../server/services/platform-server/CONTEXT.md)、[collector 上下文](../../server/services/collector-server/CONTEXT.md) 与 [collectwire](../../server/domain/collectwire/README.md)。本条合并原 ADR-0011 与 ADR-0017。
