# ADR-0055：点位语义检索归平台，对话实时卡片复用采集推送

点位名称、描述、编码及所属数据源的语义索引由 platform 持有，worker 按批对账，
复用 llmcore 的嵌入适配器和模型目录的 `knowledge.embedding` 分配。它是采集配置
的派生索引，不作为知识库文档摄取：避免复制权限域、库范围和删除生命周期。
元数据保存不等待模型；内容或模型身份不匹配的旧向量不参与召回，删除点位级联
删除索引。精确编码优先，关键词和向量共同召回；语义不可用或尚未建完必须标注。

知识库声明只读客户端工具，浏览器以当前账号调用平台搜索并打开卡片；实时值仍由
collector → 快照 → platform-publisher → realtime-hub 推送。卡片不创建现场连接，
不把持续读数送入模型或会话历史，只保存可重新解析的点位身份。历史重开时重新
读取点位配置并重新鉴权。具体契约与运行限制见 [设计](../KNOWLEDGE_LIVE_DATA_DESIGN.md)。
