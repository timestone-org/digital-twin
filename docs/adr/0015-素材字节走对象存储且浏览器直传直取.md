# ADR-0015：素材及其派生版本存对象存储

素材字节存 S3 兼容对象存储，不进数据库或容器卷。浏览器使用受大小、类型和对象键约束的签名策略直传到私有 staging，校验后进入正式前缀；公开读取由边缘代理，业务配置只保存稳定的 `asset:<uuid>` 引用。

glTF/3D 孪生模型素材的 `high` / `medium` / `low` 派生版本由 platform worker 异步生成，派生任务不覆盖原件，消费方在配置中选择 variant，而不把 variant 编进资产引用。浏览器内存不足以可靠处理大型 glTF/3D 模型素材，而 Python 缺少可用的 glTF Draco 编码链，因此 worker 镜像明确引入 Node 与 `@gltf-transform`；代价是镜像变重，但上传不占 API 进程且失败可独立重压。

本条合并原 ADR-0022。

重新上传保留素材 ID、名称与 `asset:<uuid>` 引用。模型内容每次确认均写入独立版本，上传凭证 ID 仅用于确认幂等，
校验后用数据库条件更新切换当前版本；上传失败或并发冲突不改变当前版本。
压缩任务读取版本快照，派生文件写入同一版本目录，旧任务不能发布到新版本。
模型读取通过公开的只读解析入口跳转到对象存储；解析响应禁止缓存，派生档未就绪时
使用当前版本原件。这个入口只解析已经公开的模型字节，不暴露素材名称、上传人或列表。
旧版本保留至素材删除时一并清理，以免在途请求读到 404。
