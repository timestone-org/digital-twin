# ADR-0020：写动作不抽公共外壳，竞态防护只留一份

- 状态：已采纳
- 日期：2026-08-17
- 影响范围：`web/app/src/composables/useRacedFetch.ts`、`scripts/gates/check_ts_style.py`
- 相关：[`agents/code-style-typescript.md`](../agents/code-style-typescript.md)

## 背景

前端的两条异步路径，一读一写，形态差别很大：

- **读**侧有一件深模块 `useRacedFetch`，把「可被快速切换触发的加载必须防竞态」
  这条仓规做成了接口，26 个调用方免费拿到。
- **写**侧什么都没有：25 个文件里 48 处写动作各自写一遍
  `置忙 → try → 成功提示 → 重取 → catch 报错 → finally 复位`。

一次架构评审把「给写侧也抽一件公共外壳」列成了候选。本 ADR 记下为什么**不做**，
以及真正该做的是什么。

## 决策

### 一、不给写动作抽公共外壳

判据是删除测试：抽出来的那件东西，删掉之后复杂度是**聚集**还是只是**搬家**？

先量了一遍事实——扫过全部 48 处，**没有一处漏掉 `finally`**，忙碌态一律复位。
仪式是一致正确的，不存在"每份都可能漏一条路径"这种局部性收益。

而写侧真正硬的那几条规矩，各自已经有归属：幂等键在 `api/*.ts` 的
`newIdempotencyKey`、409 冲突在 `useForceDelete`、"未校验不等于通过"在
`usePointOps.warnUnverified`。剩下能被外壳吸收的只有那 6 行样板。

更要命的是忙碌态的形状本身就不统一，而且**都是对的**：
`Ref<boolean>`、`Ref<string | null>`（哪一行在忙）、`Ref<Set<string>>`（哪几行在忙）、
外加一个 `busyLabel`。一个外壳要把这几种都收进去，参数会长到跟它替掉的 6 行一样复杂——
那是**浅模块**：接口和实现一样宽，纯粹是搬家。

⚠ 这条结论**依赖于那次扫描的结果**。如果以后真出现"某处漏了 `finally`，
按钮永远转圈"这类缺陷，那就是局部性收益出现了，届时该重开这个决定。

### 二、竞态防护只许有一份，缺的能力补进那一份

同一轮扫描发现手搓的竞态防护有 **9 处**，其中 4 处用的名字是 `generation` /
`token` / `this.loadSeq`，光靠搜 `seq` 根本找不全。

它们绕开共享件不是因为偷懒，而是因为**接口缺了一块**：其中 4 处要"作废在飞的那一次"
（卸载、关弹窗、换实例），而 `useRacedFetch` 只有"后发先至"没有 `cancel()`。
缺一个方法，就逼出了 4 份复述。

于是把缺的补上：`run` 给任务一个 `AbortSignal`，另加 `cancel()`——
中止在飞的请求，并推进序号让它之后返回也写不进状态。
⚠ 两件事都要做：中止只让请求早点返回，**拦不住已经拿到结果的那一次**写状态。

`app/` 下 7 处全部改接，并加一道闸（`check_ts_style` 的
`check_race_guards_come_from_one_place`）挡住新的手搓件。

### 三、`packages/*` 里那两处是有意留下的

`three-core` 的两处不改，理由是两条，不是一条：

1. **够不到**：`useRacedFetch` 住在 `app/`，而 `packages/*` 不许依赖 `app/`
   （`web/CONTEXT.md` §2 的四条铁律之一）。
2. **形状不同**：它们在输的那一路要 `disposeSceneGraph(root)` **释放 GPU 资源**——
   对被丢弃的结果还要干活，而共享件的输家路径没有任何回调。只 `return` 是一次纯泄漏。

闸门因此只扫 `app/`，并在自己的 docstring 里写明这条边界与放开它的条件：
**第三个包侧消费方出现时**，就该把这件东西下沉成一个零依赖包，那时再放开扫描范围。

## 代价

- 写动作的样板还在，48 处。这是一笔**有意留下**的重复：它的每一份都正确，
  而收掉它要付一个浅接口的代价。
- `useRacedFetch` 的接口宽了一点（多一个 `cancel`、任务多收一个 `signal`）。
  26 个老调用方一行没改——忽略形参的函数照样可赋值，而不用 signal 的任务
  不会被真的中止。
- 包侧那两处仍是手搓的，闸门看不见它们。这条债是显式的，写在闸门的
  docstring 与本 ADR 里，不是被忘掉的。
