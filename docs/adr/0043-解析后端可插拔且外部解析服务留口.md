# ADR-0043：知识来源与本地、外部解析后端分层

最外层扩展点是 `KnowledgeSource`；上传文件只是来源之一。来源统一产出 `RawItem`，解析层不认识来源；本地与外部解析后端都必须产出带 `locator` 的结构化 `ParsedDocument`，切块层只消费其 Block 序列。

本地解析是同步 CPU 工作，必须进进程池；外部解析是异步网络 IO，必须有超时且不自动重试。两路使用不同方法名和显式注册，已配置的外部后端优先，上传 accept 清单取两路能力并集。MinerU 是当前外部实现，用于 PDF 与扫描件；未配置时诚实缺席。

本条合并原 ADR-0033。具体协议与能力面见 [knowledge-server 上下文](../../server/services/knowledge-server/CONTEXT.md)。
