# ADR 0025：助手上下文按「多久变一次」分四层，易变的一律排在最末尾

- 状态：已接受
- 日期：2026-08-25

## 背景

百炼控制台上助手的缓存命中长期只有 ~50%。端点的前缀缓存认的是**逐字相同的前缀**，
而当时的上下文把两样每轮都变的东西放在了很靠前的位置：

1. **工作面快照与当前计划夹在常驻提示词中段**（`prompt.build_system_prompt`）。
   系统消息在 Qwen 一系的对话模板里渲染在工具声明**之前**，于是它一变，后面 25 个
   工具的 JSON Schema 与整段历史一起作废。实测断点落在第 789 字符——而静态区
   （常驻提示词 + 工具声明）在 dashboard-editor 上有 11 812 字符。
2. **历史窗口每轮脱落**（`history.window` 的裸 `[-limit:]`）。会话过 40 条之后，
   每多一条消息窗口就整体前移一格，消息区的前缀从此再也对不上。

放大器是回合形态本身：一次客户端工具往返就是一次新的 `:advance`，一个回合最多
往返 24 次，而每一次都带一份**刚被助手自己改过、因此必然不同**的新快照。命中率
是 50% 而不是 0%，只因为同一次 advance 内部 `think → use_tools → think` 是只追加的。

还有一件事让上面这些一直没被发现：**服务端根本看不见用量。** `langchain-openai`
只在用默认 OpenAI 端点时才自动开 `stream_usage`，而本服务的端点一律来自配置——
流式回包里连 `usage` 都没有，`cached_tokens` 一次也没到过我们手上。

## 决策

**一、上下文按「多久变一次」分四层，顺序即分层。**

| 层 | 内容 | 变化频率 |
|---|---|---|
| A 常驻不变 | 基本约定 | 跨会话跨页面逐字相同 |
| B 按工作面固定 | 当前位置、技能名录、工具声明 | 同一页上所有会话逐字相同 |
| C 只追加 | 历史消息 | 只在末尾追加 |
| D 每轮重建 | 工作面快照、当前计划 | 每一轮都变 |

A+B 的价值在于**跨会话共享**：修好之后，一个刚开的新会话第一轮就能吃到别的会话
留下的那 11.8k 字符前缀。改造前那一轮是必然全 miss。

**二、`build_system_prompt` 是 `surface_kind` 的纯函数。**

不再收 `context` 与 `plan`。它掺进任何一格会话自己的东西，A+B 层就不再跨会话共享。
常驻提示词里只留一句指路，说清实时状态在对话末尾。

**三、易变的那些收进末尾的 `<当前状态>` 块，且不落库。**

`services/state_block.py` 把快照与计划包成一段，作为**最后一条**消息挂上去。位置
定成「永远最后」而不分是用户发话还是工具回填——工具回填那一路没得选：那一批工具
消息与它们的调用必须相邻。它不进 `incoming_messages`，因此天然不落库：落进去的话，
一个会话每重放一次就把几十份过期快照再喂一遍，而模型分不出哪一份是此刻的。

**四、历史窗口按台阶脱落，不逐条滑动。**

`MAX_HISTORY_MESSAGES` 仍是高水位，新增 `HISTORY_DROP_STEP = 10`：起点每 10 条才
前移一次，窗口在 31–40 条之间浮动。历史区的前缀失效频率降到十分之一。

**五、每次模型调用记一条用量。**

显式开 `stream_usage`，把 `prompt` / `cached` / `output` 记进 `model_call_usage`。
没有它，上下文工程就是盲的——前缀被打断这件事没有任何运行期迹象，只有账单和延迟
会慢慢变难看。

**六、这条纪律由一道契约闸守着，不靠记。**

`tests/contract/test_prompt_prefix.py` 断言相邻两轮的公共前缀必须覆盖到历史区末尾，
也就是断点只允许出现在 D 层。谁再往常驻提示词里塞一格「当前时间」「当前用户」，
当场红。

## 后果

- 实测相邻两轮的公共前缀从 789 字符涨到 13 946 字符（12 条历史、40 个画布节点的
  快照；历史越长这个数越大）。
- 模型读快照的位置从系统提示词中段挪到了对话末尾——离决策点更近，但这是一次真实的
  行为改动，靠真机剧本验证它还认得出用户说的「这个」。
- 将来若换到需要显式声明缓存断点的供应商，断点位置天然就落在层与层之间，是加一行
  的事。
- 「往提示词里加当前时间」这类需求从此只有一个落点：D 层。进 A/B 层会把整块前缀
  打回原形。

## 不做

- 历史摘要与陈旧工具结果折叠留到下一批，且必须挂在同一个锚定台阶上重算——否则它
  自己就成了第三个断点。
