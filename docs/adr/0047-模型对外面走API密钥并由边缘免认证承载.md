# ADR-0047：模型部署使用独立部署密钥并由 platform 校验

“部署”是模型版本面向第三方的稳定 URL 与配额，和模型绑定到内部公式是两个概念。部署 URL 使用自身稳定 code，切换不可变模型版本时调用方无需改地址。

部署密钥属于部署资源，由 `platform-server` 保存高熵密钥摘要并校验，不进入 auth-server 的账号 API 密钥体系。边缘仅为精确的 `open-models` 前缀绕过账号鉴权并按 IP 限流；platform 对每个端点强制部署密钥、按密钥限流和单次行数上限，所有无效原因返回同一结果，明文只在创建时出现一次。

对外只返回模型签名、预测值和告警，不记录业务入参出参。若该负载开始影响业务 API，再为同一代码单元增加 serving 运行角色，而不是另建数据属主。
