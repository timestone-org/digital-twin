# ADR-0005：边缘负责入口，实时通道保持薄化

`edge-gateway` 负责 TLS、反向代理、前置鉴权、限流和静态资源；`realtime-hub` 只负责 WebSocket 连接、订阅和扇出，不读业务表、不解析业务载荷。服务到 hub 的内部面使用服务级密钥，业务求值、节流和重试留在推送方。

主题是不透明键，由推送方声明存在性与所需权限；可能漂移的业务实体集合由推送方周期对账。hub 只查自己的声明、订阅和匿名授权：登录连接比较权限码，公开连接比较票据指纹 grant；每主题 `seq` 由 hub 持久化并原子递增。业务实体和授权的收敛由推送方负责，hub 不回调业务服务。

具体连接、别名、配额与撤回语义见 [realtime-hub 上下文](../../server/services/realtime-hub/CONTEXT.md)。本条合并原 ADR-0007；公开大屏的产品边界见 ADR-0014。
