# 请求事务在响应与幂等回执前完成

请求使用的数据库会话在 HTTP 响应发出前结束。PostgreSQL 可以在提交时才检查约束，提前报告成功会让客户端看到实际未保存的数据。事件流先完成入口处的校验事务，后续步骤各自在短事务中持久化。

需要缓存首次成功回执的写操作，先取得幂等占位，再在同一业务事务中完成变更，收到提交确认后才发布回执。数据库明确报告事务回滚时允许同键重试。提交应答丢失时返回结果未确认，完整的幂等窗口内保留占位，防止同一请求再次执行。该窗口也覆盖提交期间的进程退出。

约束错误和数据库明确报告的回滚可以释放占位。程序保留 SQLSTATE `08007` 与 `40003` 对应请求的占位，这两个状态都表示结果未确认。[PostgreSQL 错误码](https://www.postgresql.org/docs/17/errcodes-appendix.html)
