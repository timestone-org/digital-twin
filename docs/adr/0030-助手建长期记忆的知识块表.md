# ADR-0030：助手长期记忆独立存储并显式写入

助手在自己的 `assistant` schema 保存长期记忆，写入只来自明确的 `memory.remember`，检索经 `memory.search`；它不爬取或复制 platform 业务数据。仓储层强制按调用者身份隔离，避免任何调用点忘记过滤。

记忆规模有限，向量以紧凑字节存储并在应用层计算相似度，通过 `LongTermStore` 端口保留替换实现的能力。嵌入暂不可用时先保存文本并明确标记，后续检索可惰性补算；这与 knowledge-server 的文档知识库是两个数据属主和两套语义。
