# 工作流直接训练，模板冻结结构并创建独立工作流

工作流（API 名称保留 `pipeline`）是建模的日常管理单元，直接配置、训练、保留训练记录与
不可变模型版本，不再要求先发布模板、再创建模型实例。模板仍为不可变图快照，复制模板
创建可编辑的独立工作流；模板更新不传播到副本。既有实例及其受限配置 API 保留兼容，
它们也是具有独立训练历史的工作流，而不是新流程的必经步骤。

每个工作流只有一个对外发布入口，重复发布显式替换其固定版本，保留部署身份、URL 和配额。
训练成功自动封存可服务的模型版本；是否自动更新发布入口由本次训练或持久定时规则明确选择，
未选择不改变线上版本。自动发布只接受相同任务和兼容签名，失败保留现有发布版本并单独报告；
签名变化只允许人工确认。公式绑定继续固定指向明确模型版本，不随部署换版隐式改变。
代价是历史模型及其来源训练需要引用保护，不能通过删除训练记录破坏当前发布、公式或换版历史。

账号 API 密钥继续经 auth 三道闸。`modeling:manage` 负责设计工作流、发布模板及从模板创建
可编辑工作流，`modeling:run` 负责训练与管理定时规则，`modeling:publish` 负责发布与清理模型。
启用自动发布额外要求发布权限；对外推理继续使用账号 API 密钥与 `modeling:view`，见 ADR-0062。
定时规则与训练均由 platform 持有，调度只在 worker 角色执行，不产生新的数据属主或服务。
