# 建模模板冻结结构，模型实例独立配置和训练

设计流水线发布为不可变的建模模板快照，每次发布产生递增版本；模型实例复制指定
模板版本的图，后续只修改节点参数，继续复用已有流水线执行、模型版本和部署机制。
模板更新不传播到已有实例，避免改模板时无声改变训练和线上模型。代价是实例之间
保留独立图副本；升级模板通过创建新实例显式完成，不引入共享可变图与隐式继承。

账号 API 密钥继续经 auth 的三道闸。`modeling:manage` 负责设计和发布模板，
`modeling:run` 负责从模板创建、配置和训练实例，`modeling:publish` 负责发布版本
与部署。第三方无需设计权限。资源沿用建模模块的共享权限域，不引入租户所有权。
对外推理统一使用账号 API 密钥与 `modeling:view` 权限，见 ADR-0062。

批量配置使用完整节点参数对象，按当前算子 Schema 及整图约束一次校验、原子保存，
并要求实例修订号以拒绝覆盖他人修改。Schema 来自算子代码，避免持久化第二份真源。
创建与训练支持幂等键，训练继续在提交后交给 worker；结构和运行数据的属主不变。
