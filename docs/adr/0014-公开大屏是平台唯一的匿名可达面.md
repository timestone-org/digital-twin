# ADR-0014：公开大屏使用可轮换票据，并以受限匿名实时通道取数

公开大屏是唯一无需任何凭据即可访问的业务数据面；每次发布生成新的高熵票据，撤回立即关闭 HTTP 快照，未知与已撤回均返回 404，出参不泄露内部 id。其它边缘免认证路径若由服务自身校验密钥，不属于“无凭据公开”。

同一票据可通过 `dt.public` 订阅实时数据：platform 周期登记“票据指纹 → 真主题”授权，hub 只存指纹，客户端只见 `public:<票据>` 别名，并在 accept 前执行连接配额、周期复核撤回。公开跨屏跳转只下发已发布目标的当前票据；历史数据不开放，断线时页面必须明确标为静态或陈旧快照。

本条合并原 ADR-0021；通道通用边界见 ADR-0005，具体口径见 [realtime-hub 上下文](../../server/services/realtime-hub/CONTEXT.md)。
