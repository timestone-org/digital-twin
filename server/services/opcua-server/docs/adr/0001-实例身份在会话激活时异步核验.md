# 实例身份在会话激活时异步核验

同一进程承载多个实例。固定版本 asyncua 1.1.8 同步调用用户管理器，直接在回调里访问数据库或计算 Argon2 会拖慢所有实例。服务在单个激活请求中异步读取所属实例的凭据或用户证书记录，Argon2 在原生库中释放 GIL，口令计算由事务外的线程执行，所有实例共享并发上限。调用方取消时，原生计算结束后才释放配额。核验结果绑定本次会话和任务，由上游同步回调消费一次。[asyncua 会话激活实现](https://github.com/FreeOpcUa/opcua-asyncio/blob/v1.1.8/asyncua/server/internal_session.py)

签名加密通道的应用证书标识客户端程序。X509 身份使用激活请求中的用户证书，验证有效期、登记指纹及上游签名结果。显式允许的匿名会话按节点访问权限运行。登记和撤销以新会话激活时的数据库记录为准。账号名或证书主体进入管理面的会话登记，上游角色对象只携带权限，以免诊断日志包含证书主体中的个人信息。[OPC UA Part 4 会话激活](https://reference.opcfoundation.org/specs/OPC-10000-4/5.7.3)

监听器对固定版本的协议分发点有依赖。升级 asyncua 时须通过扩展点契约测试和真实签名加密握手测试，包含账号、用户证书、匿名与撤销场景。
