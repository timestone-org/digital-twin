# 层级图上下文

层级图表达计量对象之间的上下游关系，是可以单独安装的绘图工具。

## 通用语言

**层级图项目** `project`：一份可编辑图文档及其保存版本，归创建账号所有。
不叫大屏项目或建模流水线。

**计量节点** `meter`：具有编号、圆内下栏和名称的计量对象。
不是采集点位，也不自动连接现场设备。

**汇流点** `junction`：将多个上游与下游组织成公共连接关系的元素，不占逻辑层级。

**连接** `edge`：由一个元素指向另一元素的有向关系；允许多上级，不允许循环。

**逻辑层级** `rank`：由真实连接关系推导的深度，与编号前缀和编辑位置无关。

**展示行** `row`：标准图在指定宽度内的一行。同一逻辑层级可以折返续行。

**标准图** `drawing`：按固定计量图规范生成的完整图纸，不是编辑画布的截图。

**保存版本** `revision`：一次成功保存的不可变文档；恢复历史会产生新的保存版本。
