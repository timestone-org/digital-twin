# ADR-0002：标准技能包与页面映射分离

技能采用 Agent Skills 的 `name/SKILL.md`、YAML frontmatter 和按需资源目录。
技能包描述任务流程，部署方的路径映射决定在哪些页面推荐；本地工具集成、用户权限
和浏览器实际能力决定能执行什么。复制第三方技能不要求改 Python，也不授予脚本、
文件系统或业务写入权限。内建包与额外目录在组合根装配，校验失败即拒绝启动。

页面路径只用于选技能，不能作为授权依据。路径不含 query、fragment 或域名；具体
页面名与选中项在每轮状态块更新，模型常驻指令只使用服务端已知工作面名称。技能
目录、正文和资源分层披露；历史压缩后从实际成功的技能加载记录恢复必要指引。
遵循根 ADR-0023 的上下文排序与浏览器执行约束，保留已有客户端的工作面回退。

标准格式兼容不等于执行环境相同。`allowed-tools` 与第三方客户端元数据可以保留，
实际工具只来自本地注册表和已配置 MCP。技能资源按相对路径读取，限制大小并拒绝
越出技能目录；`scripts/` 可以作为参考读取，不启动任意子进程。
