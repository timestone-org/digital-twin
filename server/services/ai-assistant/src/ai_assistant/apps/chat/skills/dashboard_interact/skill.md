# 配联动

把一块可点的模块接到别处：点一下让另几块显示 / 隐藏 / 切换，弹出一个弹窗，
或者跳到另一张大屏。

## 一条规则长什么样

**某个画布节点上发生某个事件 → 做一个动作。** 三样都要：源节点、事件、动作。

规则存在**大屏这一级**，不属于任何一个节点——所以「把这块卡片复制到另一张屏」
带不走跟它有关的规则（选中集内闭合的那几条除外）。

## 先读一次，别凭猜

`dashboard.read_interactions` 一次给三样：

1. `rules` —— 现有的全部规则，每条带一句人话摘要。
2. `sources` —— **哪些画布节点能当触发源**，以及各自发得出什么事件。
3. 每条规则的 `problems` —— 非空就是这条现在已经是哑的。

⚠ **`sources` 之外的节点当触发源配了也永远不触发。** 一块纯装饰的图片、一条
分割线不上抛任何事件，而规则照样存得下去、不报错，画面上只表现为「点了没反应」。
写的时候会被当场拒收，但先读一次能省掉那一次往返。

⚠ 用户说「联动不好使」时**先看 `problems`**：多半是源节点或目标节点被删过，
不是规则配错了。急着新加一条只会多一条哑规则。

## 八档动作，怎么挑

| 用户的话 | `action` |
| --- | --- |
| 「点一下把那块显示出来」 | `{type:'show', targets:[…]}` |
| 「点一下把它藏起来」 | `{type:'hide', targets:[…]}` |
| 「点一下来回切」 | `{type:'toggle', targets:[…]}` |
| 「切到哪个就显示哪一组」 | `{type:'setActive', groups:[{value, targets:[…]},…]}` |
| 「点开一个弹窗看明细」 | `{type:'openModal', target:节点id, title?:'…'}` |
| 「加个关闭按钮」 | `{type:'closeModal'}` |
| 「点进另一张大屏」 | `{type:'navigate', target:大屏id}` |
| 「六个指标各进各的明细屏」 | `{type:'navigateByValue', routes:[{value, target:大屏id},…]}` |

⚠ 显隐三档的 `targets` 与 `setActive` 的 `groups[].targets` 都是**画布节点 id**。
⚠ 两档跳转的 `target` 是**另一张大屏的 id**，从 `dashboards.list` 取。填成画布
节点 id 会被当场拒——那正是这一档最常见的错，而它存得下去、点下去只会跳到一张
不存在的屏。

## 弹窗：两步，缺一步就穿帮

弹窗的内容**就是画布上那个节点**，联动只是把它连同子树浮起来。所以：

1. `dashboard.set_visible`，把内容节点设成 `is_visible: false`。
2. `dashboard.write_interaction`，`action` 给 `{type:'openModal', target: 那个节点}`。

⚠ **少了第一步，屏上与弹窗里各画一份。** 写规则时回执会给一条 `warnings`
提醒你，但它拦不住——两处都不报错。

⚠ 弹窗自带关闭键、Esc 与点遮罩关闭，不必再配一条 `closeModal`；配它是为了
「弹窗里那个自定义的『我知道了』按钮」。

## 互斥切换：一个值配一组

`setActive` 是「选中值命中的那组显示、其余组隐藏」，用来做一块分段控件带动
下面换一批图表。

⚠ `groups[].value` 要与源控件上抛的值**逐字相同**——那是它配置里那一项的 `key`，
不是它的显示名。拿不准就先 `dashboard.read_config` 看源控件配了哪几项。
⚠ 值不能留空、也不能重复：不带值的事件一律不派发，留空的那组永远不命中；
同一个值出现两次只有第一条生效。

## 显隐是运行时的，不是配置

联动改的是**运行时**的显隐，节点保存下来的初始显隐它一个字都不动。
两者的分工：

- `dashboard.set_visible` 定**打开这一屏时**它显不显示。
- 联动规则定**用户点了之后**它显不显示。

所以「默认藏着、点了才出来」= 初始隐藏 + 一条 `show`。

## 三条边界，每次都要说给用户听

1. **联动在编辑器里点不出效果。** 编辑画布与预览都不跑联动引擎，要验只能
   保存之后打开这张屏的查看页。别答应用户「我截个图看看效果」——
   `dashboard.capture` 截到的是编辑态，联动在那里是不动的。
2. **规则不在撤销栈上。** 节点上的每一笔用户按一次 Ctrl+Z 都退得回来，规则
   退不回来。每次写完、删完都补一句。
3. **删规则之前先用 `user.ask` 让用户点一下确认。** 删掉的那条会在回执里
   原样交还，用户反悔就照它再写一次——那是这条轴上唯一的「撤销」。

## 一趟完整的活

用户说「点这个按钮，弹出那张明细表」：

1. `dashboard.read_interactions` —— 按钮在不在 `sources` 里、它发什么事件。
2. `dashboard.read_canvas` —— 认出「那张明细表」是哪个画布节点。
3. `dashboard.set_visible`，明细表设成初始隐藏。
4. `dashboard.write_interaction`，源给按钮、事件给 `click`、
   动作给 `{type:'openModal', target: 明细表}`。
5. 跟用户说：配好了，保存后在查看页点一下就能看到；这一步 Ctrl+Z 撤不回来。

⚠ 要动 3 条以上规则（整屏接一遍切换、一批卡片各配一个跳转）时先用
`plan.write` 把步骤列出来，每完成一项立刻更新状态。
