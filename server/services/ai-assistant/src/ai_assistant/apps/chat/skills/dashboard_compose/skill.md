# 组态大屏

在大屏画布上摆模块、改它们的配置与外观、做对齐排版。

## 先看地图再动手

`modules.catalog` 是**唯一的模块真源**：每个模块类型有什么配置字段、字段是什么
类型、有哪些可选值、哪些字段有条件显示，全在里面。

⚠ **不要凭印象填配置键**。清单里没有的键写进去不会报错，也不会生效——
画面上表现为「配了没反应」，而配置确实存下去了。

⚠ 用户说的模块名是中文（「数值卡」「按钮」），清单里每个模块带 `keywords`
（含拼音），按它对上模块类型，**不要自己音译**。

## 坐标与几何

- 设计坐标系，单位像素，原点在左上角。默认画布 1920×1080。
- 几何必须是**整数**。带小数的会被拒收。
- 加模块时不给坐标就落到默认位置；要放在某处就一起给 `x`/`y`。
- 容器类模块可以装子节点，`parent_id` 指向它。

## 外观（用户说「边框」「圆角」「背景」时）

模块外观不在配置字段里，在节点的**卡片外观**那一段，用 `dashboard.set_config`
写 `__cardStyle` 下面的键。

- 「去掉边框」= `borderStyle` 设成 `none`
- 边框风格是闭合集合：`solid` `glow` `double` `dashed` `bracket` `cut` `breathe` `none`
- ⚠ 外观键的语义是「**键不存在 = 没设置**」，与配置字段的默认值相反。
  要恢复成缺省就**删掉那个键**，不要写一个「默认值」进去。

有些模块自绘外壳，不吃统一外观键（清单里会标出来）。对这类模块改外观
不会有任何效果——**先看清单，不支持就直说，别写进去**。

## 排版

`dashboard.arrange` 做对齐与分布，一次一个动作：
左对齐 / 右对齐 / 顶对齐 / 底对齐 / 水平居中 / 垂直居中 / 水平分布 / 垂直分布 / 整理。

⚠ 对齐至少要选中 2 个，分布至少 3 个。少于这个数就直说做不了。

## 动手的边界

- 每一步都立刻显示在用户的画布上，用户能 Ctrl+Z 撤单步。
- **删除节点会连子树一起删**。删之前先说清要删什么、有几个子节点。
- 不要替用户保存。
- 一次只做用户要的那件事。用户说「加一个数值卡」，就加一个，
  不要顺手把整屏重新排版一遍。
