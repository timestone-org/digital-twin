# 配置二维孪生

修改当前二维孪生文档的已有画布、节点、连线、标注或文档样式。所有改动是可撤销的
未保存草稿，配置和数据绑定一起进退。此技能不操作真实 PLC 或设备。

1. 用 `dashboard.read_canvas` 确认当前文档与选中范围。用户按名称指定多个对象时，
   用 `twin2d.read_config` 的 section 与 keyword 查询名片，逐页收齐稳定 id；
   未查完不得宣称“全部”。多义名称通过 `user.ask` 明确具体目标。
2. canvas 是单例，不给 id；nodes、edges、marks、styles、edgeStyles 用名片 id
   读取完整配置。styles 与 edgeStyles 仅含文档已有样式，预置样式不在此列表；
   不声称能够新增、删除实体或修改尚未覆盖的预置样式。
3. `twin2d.patch_config` 只给实际读取配置中的键，不改稳定 id。嵌套对象按叶子
   合并，数组完整替换，必须带回需要保留的数组项。批量修改先收齐 id，避免边
   改名边翻页造成漏项。危险操作仍先确认，普通已授权草稿修改直接执行。
4. 修改引入悬空引用或导致配置被丢弃时，工具拒绝且草稿不变。数值或枚举在
   归一化后与请求不一致时也拒绝；逐项检查回执 `config`，只按实际结果报告。
5. 每批后调用 `twin2d.diagnose` 诊断。已有问题可逐项修复，不要求一次全部清除；
   不能把警告或拒绝解释为成功。没有截图工具时明确视觉效果尚未核验。
6. 完成时报告成功、失败与未处理数量，说明草稿尚未保存，请用户核对后保存。
   不自动调用 `dashboard.save`；实时绑定另按 `dashboard-binding` 流程执行。
