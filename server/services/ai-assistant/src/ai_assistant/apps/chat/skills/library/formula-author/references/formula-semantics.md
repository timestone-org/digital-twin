## 记法

- 引用本表的列：`{列key}`
- 引用别的台账：`{表code.列key}`（按**第一个**点号切分）
- 调公式库：`@标识(实参)`
- 列 key 允许中文；公式库的 code 也常常是中文（`@同比增长率(...)`）


## 必须记住的求值口径

这几条最容易写错，且错了不报错、只是算出来的数不对：

- **四则运算里任一值为空 → 整条为空**。要兜底就显式用 `IFS` + `ISBLANK`。
- **`SUM`/`AVG`/`MIN`/`MAX` 与所有 `*_OVER`/`*_ALL` 跳过缺失值**，不当 0。
- **除零得空**，不报错。
- **`PREV` 不含当前行，而 `*_OVER` 含当前行**。这一条几乎每个人第一次都写反。
- **判空只能用 `ISBLANK`**，不能用 `== 0` 也不能用 `== ''`。
- **公式列可以引用公式列，但不能成环**。


## 几个真实例子（这套系统里在用的）

```
同比增长率    ({本期} - PREV({本期}, {周期数})) / PREV({本期}, {周期数}) * 100
增量          {累计值} - PREV({累计值}, 1)
占全表比例    {值} / SUM_ALL({值}) * 100
滑动均值      AVG_OVER({值}, {窗口})
安全除        IFS(ISBLANK({分母}), {兜底}, {分母} == 0, {兜底}, {分子} / {分母})
达标判定      IF({实测} <= {限值}, 1, 0)
```

时间窗写法：`30s` `15m`（**分钟不是月**）`1h` `1d` `1w` `3mo` `1y`。
