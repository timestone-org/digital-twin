## 数组配置与绑定

配置数组不一定对应数据行。先用 `modules.catalog` 读取字段及 itemSchema，
再用 `dashboard.read_config` 看当前配置。`dashboard.add_config_item` 返回的
index 是配置下标；随后用 `dashboard.read_bindings` 找实际实体与槽键。
实时数值卡等模块的字段名由当前清单决定，不能固定套用 items/itemValues。

用户已指定来源时按授权绑定；来源仍有歧义时用 `user.ask` 确认。
新项不需要数据来源时，不强行创建绑定。

## 写入与删除验收

字段类型、枚举、上下限、子字段和数组下标在写入前校验。数组路径中的下标用整数，
如 ["indicators",0,"name"]。值给 null 是删除覆盖、恢复默认，其余默认项保持。
删除会使已有绑定指向另一实体时，工具会拒绝并列出受影响槽位。
先核对来源和用户授权范围，再处理这些绑定、删除配置项并按实体重新接上。
修改后重新读取配置与绑定；配置项下标不能作为绑定身份的替代。
