# 模型缺省执行由冻结推理格式决定

新发布的回归与分类推理格式 2.1 执行前置填充链中已冻结的拟合默认值，签名与推理从同一份
可服务步骤推导缺省规则，不让展示签名反向成为计算真源。只允许链首连续填充步骤
覆盖的入口缺值进入计算，未覆盖缺值保留 null，显式 0 不改变。
异常检测继续要求完整有限输入，不通过回归与分类的缺省策略放宽判定输入。

已有 1.0、2.0 模型继续按各自冻结格式计算，保留其缺值返回 null 的行为，
避免修复一个签名提示问题时悄然改变已部署模型的计算口径。
代价是历史签名中的可选提示不代表旧模型已经执行填值，接入方应核对实际格式及
新增 missing_policy；需要新缺省行为时重新发布并显式切换版本。
一旦存在 2.1 模型，读者回滚下限必须保留 2.1 兼容，不能只回退加载器。
