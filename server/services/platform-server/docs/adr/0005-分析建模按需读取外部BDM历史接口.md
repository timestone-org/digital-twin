# 分析建模按需读取外部 BDM 历史接口

分析建模的数据源允许读取授权的 BDM 点位、产供用属性与 EMS 公式历史接口，
与台账取数共同输出特征帧。外部系统仍是原始数据属主；不先复制成采集点或台账，
避免把已有历史接口变成另一条同步、归档和补洞管线。本边界是业务历史查询，
不改变 collector 独占现场设备连接的决定。

URL 和 API Key 由部署配置授权，只在 platform API 与 worker 使用，不能来自
流水线参数、浏览器或导出图。网络读取在数据库事务外执行，计算子进程只接收
不含连接与凭据的纯数据，完成帧组装和计算；排队与组装计入取数总预算。
窗口、分页、请求体积和总耗时均有上限；取数失败使对应节点失败，不用空表替代。
时间按显式来源时区转为 UTC，以时间戳对齐，缺失保留为空，截断明确标注。

上游只提供 offset 分页，无法保证查询期间的数据快照一致性。读取按标识与时间
去重，相同时间的冲突值拒绝进入训练帧；需要快照一致性时须由上游提供快照或游标。
接口形状和算子参数见根目录 `docs/MODELING_DESIGN.md` 的能管取数章节。

目录名称仅用于发现候选，历史取数始终使用真实 ID 或编码，避免同名记录串数。
上游支持名称过滤时按请求页代理，不在浏览器扫描全量目录；系统筛选能力由上游
明确声明。已有流水线不根据名称自动更换标识。
