# ADR-0014：未配置达标条件的冷启动事件保留为未评估

按开机时刻选择冻结的各机组季节范围，只有至少一个有效上下限才评估达标。
整房无条件时仍保留冷启动事件，记录 `unassessed`、空达标时刻和空达标时长。
混合房沿用已有有效范围，真正一开机即满足范围仍可为可用、零分钟。

已有工件与模型配置指纹保留。历史行不回填。旧批次只有具备有效且匹配版本的
冻结配置快照时，才按事件起始时刻识别旧的无条件结果。展示、结果过滤、覆盖统计
和训练采用同一分类。无法可靠识别的历史保持原样，可以显式重算获得新分类。

先放宽数据库约束并发布可读、可过滤的 Platform，再发布 Web 文案和筛选，
最后启用抽取写入。原有接口形状不变，应用可分批更新。写入新结果后，
数据库保留扩展约束，应用回滚版本仍须能读取新结果。
