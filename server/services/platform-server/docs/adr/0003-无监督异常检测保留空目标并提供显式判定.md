# 无监督异常检测保留空目标，并提供显式判定

设备异常检测复用流水线、不可变模型版本和独立部署密钥，任务类型为
`anomaly_detection`。正常工况样本没有监督目标，`target_key` 因而为 `null`；
不借用某个传感器列或虚构标签来满足监督模型的约束。数据库用任务与目标的联合
约束保证回归、分类仍有真实目标，输出的异常分数在模型签名中单独描述。

第三方调用 `:detect` 得到每行的异常判定、分数与阈值，频率、报警去抖和通知由
第三方控制。缺失或无效传感器输入拒绝处理，不把“无法判断”编码成正常。
模型只评价本次输入与正常工况的差异，不诊断故障原因，也不在调用中自学习。

迁移仅放宽任务集合和目标可空性，存量模型不回填。先完成迁移和全部读者的兼容
代码发布，再创建异常检测模型；已有异常版本后，不能回滚到不认识该任务/空目标的
旧代码。训练与模型扩容的行为细节以根目录 `docs/MODELING_DESIGN.md` 为准。
