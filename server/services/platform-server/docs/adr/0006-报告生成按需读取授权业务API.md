# ADR-0006：报告生成按需读取授权业务 API

报告模板允许在试算与正式生成时按报告期读取第三方业务 API，与台账有效值一起进入
既有指标、表格、图表及 Word 生成链路。它是与分析建模按需读取 BDM 一致的业务
查询边界，不改变 collector 独占现场设备会话的决定，也不增加同步、归档与补洞管线。

连接目录由 platform API 与 worker 的同一份部署配置提供。浏览器只见连接编码与
名称；地址、认证请求头和凭据不进入模板、审计快照或导出文件。模板保存已授权连接
引用、相对路径、GET/只读查询 POST、报告期参数和 RFC 6901 字段映射。模板管理
权限允许使用目录中的连接，因此部署方只登记允许报告功能读取的业务 API，路径
应限制在连接的业务查询前缀下，不登记设备写接口或通用管理接口。

API 与 worker 先结束数据库读取事务，再进行有总超时与容量限制的网络取数。
DNS 解析后校验并固定目标 IP，保留原 Host 与 TLS SNI；禁止元数据、链路本地等
危险地址，不跟随重定向，不使用环境代理，不自动重试。部署目录中的固定目标
构成出站授权，既有内网业务系统可被明确登记，不能由浏览器提供任意 origin。

API 响应通过显式记录路径、时间字段和带类型的列映射转成 `api:<code>` 数据。
相同来源在一次试算或生成中只调用一次，指标和正文节点共享这一份结果。单对象
按一行处理；数组按多行处理。源上的报告期偏移决定请求边界，禁止在消费指标上
再次叠加窗口或偏移。时刻必须带时区且处于半开报告期，缺失保留空，不以零代替。

正式生成重新获取数据；历史下载读取既有 Word，不再请求上游。生成记录保存模板
快照、经过映射的纯数据快照和核对结果，不保存原始响应或凭据。必要数据取数、
映射或计算失败时记录为失败，不交付伪成功文件；截断及陈旧等已有警告仍显式保留。

代价是第一版需要部署方登记连接，不提供浏览器凭据编辑；通用接口不猜测厂商的
分页、OAuth 续期、签名或业务信封。单源超过 1000 行或 2 MB 时明确失败，需缩小
报告窗口或由业务 API 提供有界聚合结果，不能静默截断成不完整报告。
