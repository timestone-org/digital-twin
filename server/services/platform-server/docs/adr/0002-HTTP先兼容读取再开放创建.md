# HTTP 先兼容读取，再开放创建

状态：采纳（兼容阶段）

## 背景

完整 HTTP 功能将扩展数据库协议 CHECK，并开始保存 HTTP 数据源。现有平台把
库中协议收窄成 OPC UA / Modbus；混合部署或回滚后，单个 HTTP 行即可使整个源
列表失败。关闭采集侧网络访问只限制采集请求，不限制平台创建配置。

## 决策

先发布读取兼容平台：出参使用 `ReadableProtocol`，接受 HTTP / Modbus / OPC UA；
创建入参继续使用原 `Protocol`，模型 CHECK 与迁移保持原值域。
既有 HTTP 源可以读取、仅停用或删除；点位可以读取和经过原绑定守卫删除。
源的其他 PATCH、点位创建与 PATCH、连接测试、地址浏览、现场写值在总线前拒绝。
停用仍广播计划撤销，删除保留现有历史和绑定保护。凭据不出现在出参。

只有全部旧读者退出且这个兼容版本已成为受支持回滚下限后，才可发布扩展迁移
和完整 HTTP 写面。兼容版本 SHA 必须由实际交付记录填写；本决策不宣称部署已完成。
开启完整功能时将 `Protocol` 扩为 HTTP，并删除兼容阶段的源 PATCH、点位写面
和 probe 拒绝守卫；HTTP 的 browse/write 永久只读限制保留。

## 代价

兼容阶段看到 HTTP 行也不能改配置或重新启用，只能停用/删除或升级完整版本。
这是数据库扩展后回滚到此版本时的明确降级；回滚到更早版本仍不安全。
