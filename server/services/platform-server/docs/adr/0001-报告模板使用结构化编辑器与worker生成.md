# ADR-0001：报告模板使用结构化编辑器与 worker 生成

- 状态：已采纳
- 影响：platform 报告模块、前端 Reports 页面
- 上位决策：根 ADR-0002，重任务使用运行角色，不另建服务

## 决策

保留参考项目的 ProseMirror 文档与四种业务节点语义，以当前台账公开服务面取数。
前端采用 Tiptap 结构化编辑器，界面组合使用现有 `@dt/ui`；页面设置单独存储。
服务端使用 python-docx 与原生 DrawingML 图表，位图作为可选后备。导入和生成均由
platform-worker 的专用进程池执行，经 Redis Stream 提交任务。

## 理由与取舍

参考项目的 Umo 包含独立的主题、外部资源与页面生命周期。本项目已有严格的组件、
主题与资源边界；迁移在现有组件库中提供编辑面，避免同时维护两套应用级工具栏和
主题机制。相应代价是编辑器不模拟 Word 的全部分页与复杂排版，最终版式以生成的
Word 为准；不能无损转换的导入内容必须列出，而不能假装完整保留。

这一选择不改变报告的数据来源与生成口径。模板定义、报告期、试算数据与产物的关系
见 `docs/REPORT_TEMPLATE_DESIGN.md`。API 不持有执行中的 Word 任务，重启 API
不会丢失已提交的生成请求；任务快照和幂等身份保存在 platform 数据库中。
