# 知识库整库重嵌成功后切换代次

嵌入空间按实际请求使用的端点、来源、模型名和维数标识。展示名相同的两个端点也可能给出完全不同的向量。库保留可读的模型名和维数，写向量和查询向量均核对空间标识。

管理员预览目标空间、库内容修订与块数，再显式启动重嵌。每库同时执行一个任务。后台分批把新向量写入任务专属代次，期间查询继续读取已发布代次。完成全部文档和分块后，在短事务中核对内容修订、完整性、任务归属和目标空间，一次更新已发布代次。取消或失败保留原文与当前代次。任务请求、取消和终态均可审计。

旧向量只记录来源展示名，无法证明端点身份。当前模型无法查询已发布代次或历史空间待核验时，原文和带有不完整说明的关键词检索仍可用。单文档重新解析与来源同步沿用当前库的空间；整库切换由管理员发起，后台不会主动付费迁移。

扩展结构先行，随后更新知识 API 和摄取 worker。启用新写入口前排尽旧写者，回滚期间由理解已发布代次的兼容副本提供向量读写。保留未发布任务的状态和历史数据以供核查。


同库写入按知识库、来源或文档、分块的顺序取行锁。库锁允许外键的键共享锁，批量修订触发器在源写事务中推进修订。工作者在写新向量前核对每个块的键锁；发布前核对本次需要改为就绪的文档行。遇到占用的原文时记录冲突并保留当前索引。模型与对象存储请求都在这些短事务外执行。
