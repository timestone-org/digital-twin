# ADR-0001：知识库对话使用标准技能并保留原有检索边界

知识库与 AI 助手共用 llmcore 的标准 Skill 目录、按需资源读取和工具参数校验。
知识库只有一个对话入口，固定提供本服务技能目录，不采集页面信息或维护 URL 映射。
模型根据用户问题与技能简介选择需要加载的正文；技能目录按用户权限过滤。
原有 kb.list_bases、kb.search、kb.read_chunk 及客户端采集卡片保持可用，scope
仍由会话数据库记录在工具层硬过滤，引用与标题仍沿用既有持久化和事件顺序。

推进接口只接收用户输入或工具回执，以及客户端实际能力；旧客户端请求形状保持不变。
技能恢复与资源读取计入小窗口预算，超限给出明确提示，不以半份指令假装加载完整。
摄取、解析、检索策略、模型选择、语音协议及存量会话结构保持不变。

模型输入按实际工具声明与当前可见消息逐次投影，稳定规则、范围、最近问题和当前
工具批次优先保留；历史裁剪后重新计算技能恢复。投影与图状态、持久化记录分离。
单次执行预算传给元数据工具，按完整输出计费，资源分页不接受后续静默截断。
