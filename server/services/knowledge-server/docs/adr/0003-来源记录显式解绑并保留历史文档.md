# 来源记录显式解绑并保留历史文档

平台来源以来源实例和配置选定的上游记录标识确认同一条记录。内容哈希在同一知识库内复用相同原文。同一记录再次返回相同内容时可重放，内容更改会保存新的不可变快照。记录保留当前文档和待摄取版本的关系。新版本具备可读索引后替换当前版本。原版本的文档、块、图片和对象键继续服务已经存在的引用。

上传文档和旧版未登记上游标识的文档沿用既有读取方式。只有同一来源与完全相同的原文字节可以确认存量文档归属。已有上传或其他来源仍在使用的内容继续收录。上游缺少一条记录不能证明应当删除本地资料。

管理员解绑来源后停止后续同步，保留已经导入的原文、引用和检索能力。清理资料由管理员或具备文档写权限的用户显式执行。库名、库描述和来源显示名可以独立修改。已导入数据的平台来源允许更改标题与分页参数。更换平台路径或上游标识字段时，管理员新建来源以区分记录命名空间。内置上传来源随库创建与删除。

先发布扩展结构和能够区分待处理、历史、解绑状态的知识服务读取者、同步写者和 worker，再启用管理入口与版本切换。存在新记录关系时，回滚保留能识别这些状态的服务副本。数据库和对象存储保留原内容。
