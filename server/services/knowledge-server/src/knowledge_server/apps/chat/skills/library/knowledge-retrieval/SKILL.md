# 资料检索与引用

1. 先用 `kb.list_bases` 获取本会话范围内的真实库 ID；空列表只表示当前范围无可用库。
2. 用 `kb.search` 一次查询一个主题，保留设备编号、型号和标准号。召回不足时换短查询或范围内的库。
3. 需要上下文时用 `kb.read_chunk`，chunk_id 取自实际召回。范围外被拒时请用户修改会话范围，不扩大查询。
4. 每句资料结论只挂实际支撑它的 `mark`；系统负责编号和引用列表，不能编造角标或依据。
5. 资料矛盾时列出差异，缺依据时说明缺项。查询失败不能说成没有资料。

涉及长文、截断或引用核对时，读取 [检索与引用](references/retrieval.md)。
