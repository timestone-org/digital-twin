# 边缘账号显示名随签名身份传递

业务审计以已验证的账号 UUID 标识操作者。需要展示账号名时，认证服务从同一份账号状态取用户名、角色和权限，随有效期签发。普通边缘鉴权与长任务的身份续签遵循同一契约。

`X-Auth-Sig` 沿用已有格式。认证服务同时发送 `X-Auth-Sig-V2`。后者使用独立的版本标识和确定的字段顺序，覆盖原始账号 UUID、编码后的用户名与角色、权限串及过期秒数。接收服务验证所收到的签名；缺少第二份声明时，显示身份取已验证 UUID。已提供的第二份声明无法核验时，拒绝本次身份。

先发布共享编解码和显式传递该头的边缘、助手及知识服务，再发布双签的认证服务，最后更新读取者。旧签发者与新读取者配合时，旧请求继续以 UUID 记入审计；新签发者与旧读取者配合时保留现有验证格式。所有读取者升级后，审计显示已有覆盖证明的账号名。回退签发者或中继会使新版服务回到 UUID 显示。回退读取者将恢复旧版的审计保证，因此回退时保留已升级读取者提供写服务。
