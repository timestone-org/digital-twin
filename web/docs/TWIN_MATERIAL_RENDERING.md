# 3D 部件半透明渲染

部件的 `look.opacity` 与距离淡出相乘，应用在原始材质的不透明度上。
普通不透明网格被配置为半透明时，保持标准透明混合与关闭深度写入，
不使用会产生颗粒的哈希透明。

Three 的透明队列只按整个网格排序；建筑外壳包含不同朝向的墙面，
网格内部必须按当帧相机的空间深度从远到近重排三角形索引。
双面材质同步启用 `forceSinglePass`，避免引擎再把已排好的墙面拆成
“全部背面、全部正面”两次绘制。顶点、法线、UV、材质分组和节点变换保持原样。

`PartMaterials` 持有独占索引排序副本与原始渲染回调。相机视向、网格变换
和位置数据不变时复用排序；恢复不透明或释放时还原原件，再释放副本。
部件预览为自己的相机另建副本，关闭时只释放预览资源。

排序只用于静态、每网格不超过 20,000 个三角形的普通材质，控制转动相机
时的 CPU 开销。骨骼、变形、实例化网格和特殊材质沿用自身渲染方式。
此方法修正单网格内部的墙面顺序，不承诺任意相交网格或深度循环的精确透明；
这些资产仍需拆分相交表面。已有建筑主体及附件均在排序范围内。
