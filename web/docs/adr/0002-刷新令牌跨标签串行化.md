# ADR-0002：刷新令牌在标签内合并，并尽力跨标签串行

一次性 refresh token 在同一标签内通过共享 single-flight 合并；支持 Web Locks 时，不同标签对刷新临界区排他，并在入锁后重读持久化令牌。锁不可用或等待超时时允许继续执行，正确性再由失败后重读最新状态兜底，因此跨标签串行是强优先而非绝对保证。

登录、轮换和登出通过 storage 事件通知其它标签，但接收方始终重读当前存储，不把事件载荷当权威快照。代价是旧浏览器或被冻结的持锁标签仍可能发生一次碰撞，但不应因此误删另一标签已写回的新会话。
