# HTTP 读取兼容先于创建入口

状态：采纳（兼容阶段）

后端以后版本将返回 HTTP 数据源。前端先用 `CollectReadableProtocol` 接受该
输出，创建输入仍使用原 `CollectProtocol`，创建菜单继续只提供 OPC UA / Modbus。
HTTP 列表、实时值、点位搜索、历史查询与配置导出可以读取；源可以停用和删除，
点位可以经过原绑定保护删除。HTTP 配置编辑、重新连接、测试、建改点位、导入、
归档开关和批量配置修改不提供入口，源表单和操作函数同时拒绝提交。

这份前端与先行平台兼容版本共同形成以后扩展数据库后的回滚下限。发布完整
HTTP 创建与编辑入口前，须证明所有旧读者退出并记录真实兼容版本 SHA；本记录
不证明部署已完成。完整版本移除临时拒绝守卫，但保留 reader 类型与永久只读的
现场 browse/write 限制。
